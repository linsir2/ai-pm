## 1. Goal

**技术债**：记忆抽屉 `.prop` 布局（L23 同族）· 讨论 turn 上限进 `/schema.limits`（M9 有意留白）·
03 满轮 ⬜ 真跑补记 · G10① 记账 · 问卷题快照断线上线（分析时新发现）。
**功能**：选区把手「就这段聊聊」+ 条目工具行「讨论」（D2 设计 A）；开聊卡「先跑一轮调研」
（findings 当开题底稿）；灵感卡「拿去验证」。

成功判据（都可验）：

1. 记忆抽屉正文全宽（截图 + 结构钉测试）；
2. `max_discussion_turns` 随 `/schema` 下发，前端只留离线回落；
3. 满轮真跑：6 说什么 → 第 7 说 409 `invariant:T4`、线程原样；
4. 选段 → 把手 → 讨论页签预填；900 宽把手不出现；
5. 「先跑一轮调研」真跑：探索 7 候选 → 线程 `findings_count=7` → 说一轮提示词命中底稿原文；
6. 「拿去验证」真界面：新趟候选回箱、范围标签带焦点说明；
7. 全量绿：后端 pytest+ruff、前端 vitest+tsc、parity 45=45、openapi 冻结不动。

## 2. Architecture（两条新链）

```
A) 先跑一轮调研（M13）
开聊卡勾选 → POST /explorations{scope:{document, text:主题}}（同步真跑，候选进箱）
           → status!=done？抛 exploration_failed（banner，不开线程）
           → POST /discussions{finding_exploration_id}
                → 校验（404/同项目/DONE）→ 快照全部候选为 FindingRef[]（只引用）
           → 每次 say：读 refs → 解析候选 → $related_findings 注入提示词（未经验证）

B) 选区把手 / 条目「讨论」 / 「拿去验证」（零新端点）
选区/条目/卡原话 → discussionTopic（归一化+截断 200）→ 锚点 + 切讨论页签 → 既有 M9 通道
箱内卡「拿去验证」→ POST /explorations{scope:{document, text:卡片原话}} → 候选回箱
```
