# PostgreSQL 全量切换实现计划（v2）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.
> T1–T9 中间态不可合并；T10 才删 SQLite 并启用 no-sqlite 守卫。每任务按 **R → I → P → R2**。

**Goal:** 删除 SQLite 运行时/测试/脚本，全量切 PostgreSQL 18 + pgvector；列类型换原生 `timestamptz/jsonb/text[]/boolean/bytea/bigint identity/vector`；backend 走 PgBouncer transaction mode，init/maintenance 直连。

**Architecture:** Caddy → backend × N（每 worker 一条 psycopg3 sync 连接，`prepare_threshold=None`）→ PgBouncer → PG18；init/maintenance/backup 直连 PG。UoW autocommit + 显式 BEGIN/COMMIT/ROLLBACK；模型/网络永远在 UoW 外；round 读改写 `SELECT ... FOR UPDATE`。JSON 负载内部 ISO、3 个 `''` 哨兵列、epoch lease 列保留原表示；其余列用原生类型。

**Tech Stack:** Python 3.13 / FastAPI / PostgreSQL 18 / pgvector 0.8.7 / PgBouncer 1.26 / psycopg3 / Redis / Caddy / React 18 / pytest / vitest。

**Spec:** `docs/plans/2026-10-27-PostgreSQL-全量切换-设计.md`
**影响清单:** `docs/plans/2026-10-27-PostgreSQL-全量切换-影响清单.md`

- **T1**：`connect` 用 `row_factory=dict_row` + `options="-c timezone=UTC"`，不传 `timezone=`；Settings 拆 `AppSettings.from_env()`（app URL）与 `OpsSettings.from_env()`（direct URL）；backend/init/maintenance 各自只认自己的 URL；T1 不删 SQLite/`sqlite-vec`。

- **T4**：所有 round 读改写（claim/SkipSeat/review/auto-approve）`SELECT ... FOR UPDATE`；skip 与 review 锁同一 round 行；unique 冲突后不继续 aborted 事务。
- **T6**：加入 `application/lease.py`；acquire/renew 用 `clock_timestamp()` 生成/比较 expiry；`holds()`/写路径用 DB 时间；`PgConnection` 断连重连（事务外重连，事务内 503）；无 `current_token` 借锁。
- **T7**：`init_db.py --schema-only` →（ETL）→ `--finalize`；fresh `--all`；app 不 seed/migrate；maintenance 独立 direct job + `pg_try_advisory_lock`；PgBouncer SCRAM/auth_file/admin/app/owner 角色；`/api/ready` 查 DB 并把 compose healthcheck 改它；backup 用 PG18 `pg_dump -Fc`，scratch `pg_restore --no-owner`，恢复后 `TRUNCATE sessions`；ETL 脚本不进镜像。

- **T9**：schema-only init 后 ETL 前按 `created_at DESC, rowid DESC` dedupe running；skip `sqlite_%`、`material_chunks_fts%`、`material_chunks_vec%`、`sessions`；feature-detect v15/v17/tool_calls/round_skips/vector_meta；重复 `(project_id,sha256)` 报错中止；ETL 后 `--finalize`。native 类型/JSONB/timestamptz/text[]/bool/bytea/seq/tokens 按设计 §3。
- **T10**：删除 SQLite/`sqlite-vec`/旧脚本；no-sqlite 守卫 AST+SQL 字面量，ETL 脚本/测试白名单；4 workers 负载门（0 错误/超时/55P03/57014、HTTP p95≤2s、100 HTTP + 20 轮内动作；DB p95 只作诊断）；全量 + 终审。


## Global Constraints

- 无 SQLite 运行时/双后端/降级/双写；无自研连接池；PgBouncer 是唯一池。
- backend 只走 `PMSTUDIO_DATABASE_URL`（pgbouncer:6432）；init/maintenance/backup 只走 `PMSTUDIO_DIRECT_DATABASE_URL`（db:5432）；缺失各自失败，不互相推导。
- 不引 SQLAlchemy/asyncpg；不引主从/读副本/外部向量库；不依赖 session `SET`/advisory/LISTEN/临时表；只用事务内 `SET LOCAL`。
- 模型/联网/Tavily 在 UoW 外；UoW 内不 await；round 读改写必须 `SELECT ... FOR UPDATE`。
- 类型例外写死：JSON 内部 ISO 不换；`observations/round_digests/inspirations.created_at` 保留 TEXT + `''`；`lease_expires_at`/`round_skips.requested_at` 保留 epoch ms BIGINT。
- 写入路径唯一、E 号只由账本发、owner 手写过滤；无 RLS。
- 中间态分支不可合并；旧 SQLite 只作回滚备份；T10 删除。
