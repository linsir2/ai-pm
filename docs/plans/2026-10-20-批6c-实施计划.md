# 批 6c 实施计划：联网材料入库口径改造

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让联网检索入库**整页正文**（现状是 Tavily 按 query 挑的 3 段片段），检索命中 29% → 71%，每轮向量成本不升反降。

**Architecture:** Tavily 网关请求带 `include_raw_content="markdown"` → 网关优先取 `raw_content`（null 回退 `content`）→ 清洗多剔一种导航行 → 联网材料只向量化每份前 8 块（FTS 覆盖全部块）→ 老材料按 `warnings` 里的原查询后台重搜。**零新依赖、零 schema 变更、零新端口、零界面改动。**

**Tech Stack:** Python 3.13 / FastAPI / SQLite + FTS5 + sqlite-vec / httpx / pytest

**Spec:** `docs/plans/2026-10-20-批6c-联网材料入库口径.md`（本计划实现它；判据表在 §6）

    ]

```python
class RefreshStaleWebMaterials:
    """把「片段版」的联网材料换成「整页版」：按它原来的查询重新搜一遍。

    **为什么需要**：老材料存的是 Tavily 按 query 挑的 3 段（`content` blob 只是块文本
    拼接，**拿不回整页**）→ 只能重新搜。
    **原查询读得回来**：`ParsedMaterial.warnings` 里有「来自检索：{query}」。

    三条纪律：
    ① **已被编号引用的不改写**——编号指向它里面的块，改了等于让编号改指；
    ② 幂等：刷完 `parser_version` 对上，不再 stale → 下次不再搜；
    ③ 失败不抛：网络失败就留着 stale，下次再试。
    """

    def __init__(
        self,
        *,
        materials: MaterialStore,
        parser: MaterialParser,
        index: WorkspaceIndex,
        uow: UnitOfWork,
        clock: Clock,
        vectors: MaterialVectorIndex = NO_VECTORS,
        web_search: WebSearchGateway | None = None,
    ) -> None:
        ...

    async def __call__(self, *, project_id: ProjectId) -> int:
        """刷这个项目里该刷的联网材料，返回刷了几份。"""
        current = self._parser.identities()
        summaries = self._materials.list_for_project(project_id, current=current)
        references = self._index.material_references(project_id)
        refreshed = 0
        for summary in summaries:
            if not summary.stale or summary.origin != "web_search":
                continue
            if references.get(summary.material_id):
                continue  # 已被编号引用 → 不改写
            query = _query_from_warnings(summary.warnings)
            if not query or self._web_search is None:
                continue
            try:
                packets = await self._web_search.search(query=query, limit=_REFRESH_LIMIT)
            except Exception:  # noqa: BLE001 —— 网络失败不阻断刷新
                continue
            refreshed += self._apply(packets, project_id=project_id)
        return refreshed
```

`_query_from_warnings(warnings)`：找以 `"来自检索："` 开头的，取后面的部分。

`_apply(packets, ...)`：对每个 packet：
- 去重键 = `sha256("web:" + source_ref)`（**与 `SubmitOpening._keep` 同一把尺子**）；
- `find_by_sha` 命中 → 该 URL 已有材料 → `refresh(material_id, parsed=..., content=...)`；
- 没命中 → `put(...)`；
- 事务外 `vectors.write(material_id)`（**与 `_keep` 同一纪律**）。
