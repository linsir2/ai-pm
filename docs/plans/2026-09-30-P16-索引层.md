> 设计稿见 `docs/plans/2026-09-30-P15-剩余核对-包B-包C整块能力.md` §2.2。

**Goal：** 让"跨轮"这件事看得见、找得到：**这个项目走过哪些轮**（F4 + 上一轮的主张），
以及**在这个项目里搜得到东西**（F6：条目 / 功能 / 编号 / 席位发言）。

**Architecture：** 一条只读通道，三个任务——
① `WorkspaceIndex.list_rounds()`（只读 `rounds.payload` 头部，**不建表、不缓存**）+ `GET /projects/{id}/rounds`；
② 同一列表上补"这一轮说过什么"的摘要（`claim_headlines`）；
③ `SearchProject`（文档聚合 + 账本 + 最近 N 轮的席位发言，**现查现算**）+ `GET /projects/{id}/search?q=`。

**Tech Stack：** Python 3.13 + Pydantic v2 + FastAPI + SQLite；前端 React 18 + Vite 6 + TS strict。

**Spec：** `.codex/docs/设计/04-未决.md` F4 / F6 / `06-前端.md` §5（"上一轮的主张"）；
`02-编排与数据.md` §11.0.10（"跨轮的真相源只有文档"）、§11.0.13（去重只覆盖本轮）；
`05-DDD架构.md`（动作表）。

## 4. 数据流（做完之后）

```mermaid
flowchart LR
    U[闭环区顶部：这个项目走过 3 轮] --> API1[GET /projects/id/rounds]
    API1 --> IDX[WorkspaceIndex.list_rounds<br/>只读 rounds.payload 头部]
    IDX --> HEADS[RoundHeadView × N<br/>时间 / 输入摘要 / 主张 N / 问卷 M / 写入 vK / 头 3 条主张]
    HEADS --> UI[点一行 → 只读看那一轮<br/>复用已有 GET /rounds/{id} 与 historyRound]
    Q[顶栏搜索框] --> API2[GET /projects/id/search?q=]
    API2 --> S[SearchProject：文档聚合 + 账本 + 最近 10 轮席位发言]
    S --> HITS[SearchHitView × ≤50]
    HITS -->|entry| J1[切章节 + 滚到条目 + 闪一下]
    HITS -->|feature| J2[切到 s5 + 滚到那块]
    HITS -->|evidence| J3[走已有出处跳转]
    HITS -->|opinion| J4[切到那一轮（只读）]
```
