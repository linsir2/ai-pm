**Goal：** 让"模型报文不合格"不再等于"这一轮白跑"——给 claims 补上与整合者对称的
**一次重装**（把上一次错在哪喂回去），两次都过不了才判这一轮失败。

**Architecture：** 重装是**用例层的一圈循环**，不是网关的事（网关那一圈只处理传输异常，
而且已经 `MAX_ATTEMPTS=3`）。第二次调用**必须带纠错指引**——拿同一句提示词再撞一堵墙是
`learnings.md` L13 定性过的失败模式。指引由纯函数 `repair_note()` 生成，**只给"第几条、
哪个字段、要求是什么"，绝不复制模型写错的那串内容**（`（隐含于上下文…）` 这类说明被当
`raw_span` 填过两次，复制回去等于给它一个可以照抄的模板）。失败出口一字不改：两次都过不了
→ 整轮 `failed`，理由写清"两次都过不了校验"。

**Tech Stack：** Python 3.13 + FastAPI + SQLite + LiteLLM + LangGraph；React 18 + Vite + TS。

**Spec：** `.codex/docs/设计/02-编排与数据.md` §7（失败、暂停与恢复）、§11.0.1（诊断材料的

## 0. 现状核对（对着代码，不对着印象）

| 设计里写的 | 代码里的事实 | 差在哪 |
|---|---|---|
| `04` E3：整步失败仍可重试 | 整合者有重装：`_integrate_with_repair` 循环 2 次，第一次的错误经 `validation_error` 槽喂回去（`use_cases.py:578-650`）；`Integrator.integrate(validation_error="")` + `integrator.md` 的 `$validation_error` 槽 | **claims 一次都没有**：`StartRound.analyze` 调一次，`PacketParseError` 直接 `fail_round` + 抛（`use_cases.py:189-215`） |
| `04` C9：重装不许原地撞墙 | 整合者喂的是上一次的 `message` | claims 连一圈都没有，谈不上喂什么 |
| `02` §7：一轮的调用上限 | 三条上限：席位轮 3 次、问卷 2 批、整合重装 2 次（最坏 ≈ 28 次） | 本计划加第四条：**claims 重装 1 次**（最坏 ≈ 29 次） |

**真模型证据（完整 eval 三轮，同一套输入）**：claims 这一步崩过 4 次（第一轮 `case-a` +
`edge-long`、第二轮 `edge-one-constraint` + `edge-long`），每次整轮 `failed`，用户只能手动重试，
而重试**换个采样就过了**（`case-a` 改前 3 次里崩 2 次，同一份坏报文的重跑就过）。
其中 3 次是提示词/守卫的问题（已在前两项里修掉），剩下的（如"说明当原话"）是**模型抖动**——
抖动不该由用户手动兜。

**为什么是"重装"而不是"再调一次"**：`L13` 的原话是"重试拿同一句提示词再撞一堵墙"。
把上一次错在哪喂回去，第二次才有的放矢；代价是提示词多一个槽位（约 20 字）。

**不做（列出来，免得变成半成品）**

| 不做 | 理由 |
|---|---|
| 把整合者的 `validation_error = message` 也换成 `repair_note()` | 整合那条路已经在工作（有测试钉着 `test_integrate_round_repairs_once_when_validation_fails`），而且它的 `message` 本身就带细节（未知编号会列出来）。没有证据说明它不够用，就不动它——`repair_note` 只接 `PacketParseError`，接不了整合那边可能抛的 `DomainError`（两套异常不许互相继承） |
| 在 `Round` / `RoundView` 上记"重装了几次" | **第二份真相源**。留样表 `model_calls` 按 `round_id + purpose` 数一下就知道（claims 一步一轮只该有一次调用，出现两次就是重装过）。诊断是我（作者的人）的活，不是产品功能（`02` §11.0.1 同一口径） |
| 在闭环区加一条"正在重装"的展示 | YAGNI：用户关心的是草案/问卷，不是内部重试。真要查用留样表 |
| 对 `ModelCallFailed` 也重装 | 网关那一圈已经是 3 次尝试 + 退避；报文重装解决不了网络与供应商 5xx |
| 给猜测/无原话的主张开一条"合法出口"（如 `raw_span` 可空） | 那是改契约（schema + 领域 + 归属），要单独拍板。本计划只做"重装" |

**失败出口的语义（不许变）**：两次都过不了 → 这一轮 `failed`，理由写清重装过
（`主张两次都过不了校验：<原因>`），用户可以点"重试"再来一轮。**不静默降级**——
claims 是一轮的地基，没有主张就没有去处与编号，硬编一份出来比失败更糟（GB1）。

```python
"""把上一次的报文错误翻译成"给模型看的一句纠错指引"（重装时才用）。

两条规矩：

1. **重装必须带纠错指引**：拿同一句提示词再撞一堵墙是 `learnings.md` L13 定性过的失败模式。
2. **不复制模型写出的内容片段**（`raw_span`、正文、选项措辞一个都不回喂），只说"第几条、
   哪个字段、要求是什么"。把写错的那串原样喂回去，等于给它一个可以照抄的模板——
   `（隐含于上下文…）` 这类说明被填进 `raw_span` 过两次（L20）。
"""

from pmstudio.application.errors import PacketParseError

#: 说不上具体是哪一种时的兜底话术
GENERIC = "请按上面的硬规矩重新切一遍，只输出 JSON Schema 要求的那个对象。"


def repair_note(error: PacketParseError) -> str:
    """上一次的 `PacketParseError` → 第二段提示词（纯函数，可离线测）。"""

    lines = [f"上一次的报文没通过校验：{error.message}"]
    details = error.details
    if "claim_id" in details:
        position = details.get("position")
        where = (
            f"第 {position} 条主张（{details['claim_id']}）"
            if isinstance(position, int)
            else f"主张 {details['claim_id']}"
        )
        lines.append(
            f"{where}的 raw_span 在用户输入里找不到对应的连续原话。"
            "raw_span 必须逐字取自用户输入、而且连续出现；"
            "这条主张在原话里没有落点，就不要切它。"
        )
    elif "seat_id" in details:
        lines.append(
            "席位提名里有目录里没有的 id。seat_id 只能从上面的席位目录里原样照抄，"
            "连 `seat.` 前缀一起（目录里写的是 `seat.tech_approach`，就写 `seat.tech_approach`）。"
        )
    elif "errors" in details:
        lines.append(
            f"过不了 schema 的字段：{_schema_paths(details['errors'])}。"
            "字段名与取值都只能取 schema 里列出的那些。"
        )
    elif "offset" in details:
        lines.append(
            "返回的内容不是一个完整的 JSON 对象：只输出那个对象，"
            "不要解释文字、不要代码块围栏。"
        )
    else:
        lines.append(GENERIC)
    return "\n".join(lines)


def _schema_paths(errors: object, *, limit: int = 5) -> str:
    """pydantic 的 `errors()` → `claims.2.label` 这种字段路径（最多列 `limit` 条）。"""

    if not isinstance(errors, list):
        return "(未知字段)"
    paths = [
        ".".join(str(part) for part in (item.get("loc", ()) if isinstance(item, dict) else ()))
        or "(根)"
        for item in errors[:limit]
    ]
    return "、".join(paths) or "(未知字段)"
```

```python
        # 读取不开事务：模型调用不能包在事务里，也没必要读到同一快照。
        # 重装期间这一轮没有任何写入，所以文档现状与用户输入读一次就够。
        round_ = self._rounds.get(round_id)
        document = self._documents.get(round_.project_id)
        user_input = round_.user_input
        view = document.view()
        document_state = render_document_state(view, readiness=self._checker.check(view))
        repair = ""
        for attempt in range(1, MAX_CLAIMS_ATTEMPTS + 1):
            try:
                analysis = await self._analyzer.analyze(
                    user_input=user_input,
                    document_state=document_state,
                    round_id=round_id,
                    validation_error=repair,
                )
                break
            except PacketParseError as error:
                if attempt == MAX_CLAIMS_ATTEMPTS:
                    # 两次都过不了：判这一轮失败（claims 是一轮的地基，没有主张就没有
                    # 编号与去处，硬编一份比失败更糟）。理由里写清重装过，便于复盘。
                    reason = f"主张两次都过不了校验：{error.message}"
                    fail_round(
                        rounds=self._rounds,
                        round_writer=self._round_writer,
                        uow=self._uow,
                        events=self._events,
                        clock=self._clock,
                        round_id=round_id,
                        reason=reason,
                    )
                    raise PacketParseError(reason, purpose=PURPOSE) from error
                repair = repair_note(error)
            except ApplicationError as error:
                # 网关那类（超时 / 供应商 5xx）：网关自己已经重试 3 次，重装帮不上忙
                fail_round(
                    rounds=self._rounds,
                    round_writer=self._round_writer,
                    uow=self._uow,
                    events=self._events,
                    clock=self._clock,
                    round_id=round_id,
                    reason=error.message,
                )
                raise
        else:
            raise AssertionError("不可能走到这里")
        with self._uow:
            round_ = self._rounds.get(round_id)
            document = self._documents.get(round_.project_id)
            ledger = self._evidence.get(round_.project_id)
            assigned = self._assigner.assign_claims(
                analysis.claims, ledger=ledger, round_id=round_id, now=self._clock.now()
            )
            round_.attach_claims(assigned)
            # 席位名单跟着主张一起落：它是这一次判断的产物，重试/刷新都该看得见
            round_.nominate(analysis.seats)
            authorize_named_features(round_, assigned, document=document)
            self._evidence_writer.save(ledger)
            self._round_writer.save(round_)
        _publish(self._events, self._clock, round_)
```

## 3. 成功之后是什么样

1. **抖动不再由用户兜**：claims 报文不合格时，系统自己带着"第几条、错在哪、要求是什么"
   再问一次；只有两次都过不了才判这一轮失败，失败理由写明"两次都过不了校验"。
2. **与整合者对称**：两步模型产出各有一次重装机会，口径写在 `02` §7 与 §11.0.5 一处。
3. **反编造没有放松**：重装不改任何校验；两次都过不了仍然是失败，不会静默降级。
4. **可复盘**：留样表里能看出哪一轮重装过（claims 一步出现两条调用），不需要新字段。
5. **门槛没被糊住**：单测把三条行为钉死（重装带指引 / 两次失败判死 / 网关失败不重装），
