## 0. 先把"到底怎么用"说清楚（这批的设计起点）

### 0.1 材料这条链，今天怎么用

```
三条入口                一个契约                  一个决策点              两个出口
 上传文件 ─┐
 联网检索 ─┼─► ParsedMaterial ─► MaterialStore.put ─► select_chunks ─┬─► 只给选中的块发 external 编号
（今天没有）┘   （解析草稿）        （唯一盖章点）      （预算 4000 字）│    → Round.materials → $external_material
 按网址抓                                                          └─► 没选中的块仍在 material_chunks
                                                                        （材料库列得到、F6 搜得到，只是没编号）
```

四步用法（今天就能走通）：

1. **带材料**：输入框旁边「＋ 带材料」传一份 → 后端**真解析** → 进"这一轮材料"；
2. **起轮**：`select_chunks` 挑块 → 只给挑中的块发 `E` 编号 → 渲染进 `$external_material`
   （席位 / 主张 / 整合三处提示词都有这一节）；
3. **材料库**：`材料库（N）` 抽屉列全部材料，三个动作——`带进这一轮`（只动本轮选择）/
   `重解析`（用当前解析器重读原始字节）/`删掉`（**编号发出即冻结**：被引用过的删不动，409 列出编号）；
4. **联网检索**：分析者提名 0–3 条检索词 → **复述卡勾选（默认不勾）** → 真 Tavily →
   每条一个信息包（300 字摘要）→ 与材料同一条证据链。

三条铁律不变：材料**永远不写文档**；材料**不算权威**（只引材料的提案降级成"它提议的"，
硬标 `derived` 被 `E4` 拒）；**抽不出文字就说抽不出**。

## 2. 口径（建议 + 备选 + 为什么）

1. **切在哪**：`.docx` + 按网址抓（+ `.xlsx` 建议同批）。备选只做抓网页——代价是 PRD 还得另存。
2. **抓来的网页走哪一支**：**材料支**（块级、全文、4000 池），不是检索结果支（300 字 / 2000 池）。
   理由：它是用户**点名**的材料，不是搜出来的线索；代码也天然这么分流（`origin != "web_search"`）。
3. **原始字节存什么**：存**抽回来的那份 HTML 字节** → "重解析"有真东西可读（与 `web_search`
   的"快照不许重解析"形成对照，测试钉住）。
4. **同一个网址再抓**：**刷新**（照 P19 两条路）——没被引用过 → 就地换内容与块
   （`material_id` 与去重键都不动，前端"本轮选了哪几份"不受影响）；有编号 → **另出一份**
   （变体键 `fetch:{url}|{sha256(新字节)[:12]}`），旧的冻结留着。备选：永远幂等复用——网页改了
   内容却永远拿不到新的，用户还以为点坏了。
5. **URL 进不进提示词**：建议给非 `upload` 来源的材料头补一行"来源：URL"。理由：模型该知道自己
   读的是**用户点名的那个页面**；`render_materials` 的 `budget` 参数不裁剪（只按 eid 渲染），
   所以**不动"编号 == 带进提示词的块"**那条不变量。
6. **抓取护栏**（宁可拒，也不打坏）：
   - 只允许 `http` / `https`，URL 不许带账号密码；
   - **拒绝私网 / 环回 / 链路本地**（`ipaddress` 判 `127/8`、`10/8`、`172.16/12`、`192.168/16`、
     `169.254/16`、`::1`、`fc00::/7`、`fe80::/10`，含 `localhost`），报人话
     （"这是内网地址，先把它导出成文件再上传"）；
   - 重定向**自己跟**（`follow_redirects=False`，≤3 跳），**每一跳重新判私网**；
   - 超时 15s、响应体上限 5MB（边下边数）、`Content-Type` 必须是 `text/html` /
     `application/xhtml+xml` / `text/plain`；UA 写明 PM Studio；
   - 失败一律 `ToolCallFailed` → **422**，消息说清哪一步（超时 / HTTP 状态 / 不是网页 / 太大 / 内网）。
   为什么这么严：这套 API **没有鉴权**，任何页面都能诱导本机后端去抓内网地址（CSRF 型 SSRF）。
   备选：默认放行私网（想抓自己的内部 wiki）——那得先给 API 加鉴权，是另一件事。
7. **`identities()` 加身份**不会把老材料误判成"建议重解析"：判据是"这份材料自己的身份在不在
   当前集合里"，加新条目只让**新格式**合法。
8. **不新增 DTO 字段、不改提示词槽**——这批的验收点之一就是"**换实现不是改架构**"。

## 5. 数据契约表（谁赋值 → 谁消费）

| 字段 / 接口 | 谁赋值 | 谁消费 |
|---|---|---|
| `ParsedMaterial.origin = "web_fetch"` | 抓取器 | `ORIGIN_TITLES`（提示词那个头）/ 材料卡"来源：抓来的网页" / 提示词分流 |

## 6. 成功之后长什么样（自检，逐条可验）

1. 传一份 `.docx` PRD → 材料卡写"需求.docx · N 块 · 由 python-docx 抽出"；起轮后席位真读到标题与
   表格行，提示词里带 `[E12] 表格 1（表头：角色、能否导出）`。
2. 粘贴公开网址 → 材料卡写"来源：抓来的网页 · N 块 · bs4-html"；点编号看到原文 + URL。
3. 同址再抓：没被引用过 → 内容更新（还是那一行）；已被引用 → 多一行，旧的写"已经发过编号 E7，不能删"。
4. 粘贴 `http://127.0.0.1:8000/…` → 422"这是内网地址，先把它导出成文件再上传"，**一次请求都没发**。
5. 粘贴指向 PDF / 图片的地址 → 422"这个地址返回的不是网页（application/pdf）"。
6. 抓来的网页**可以重解析**；联网搜回来的**仍然不许**——两条各一条测试钉住。
7. `.pptx` / `.doc` / 扫描件照旧 422，消息说人话。
8. 将来换 docling 仍然只改组装点一行：信息包形状没变、DTO 没多字段、提示词槽没多一个。
