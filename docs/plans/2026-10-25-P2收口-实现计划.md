### 0.4 预算公式（唯一口径）

```text
usable = MATERIAL_BUDGET - SECTION_OVERHEAD              # 4000 - 204 = 3796
pinned_cap = int(usable * PINNED_BUDGET_SHARE)           # 2277
auto_reserve = usable - pinned_cap                        # 1519
auto_feasible = 存在非手勾候选块，其 first_of_material 成本 <= auto_reserve
若 auto_feasible=False：auto_reserve=0, pinned_cap=usable
```

- `PINNED_BUDGET_SHARE` 仍是唯一可调参数；40% 是派生值，不是新开关。
- 用 `pinned_cap=int(...)` 而不是 `auto_reserve=int(...)`，保证“手勾 ≤60%”严格成立；自动拿余数 1519（40.02%），文档不再写“正好 1518”。
- `auto_feasible` 用真实渲染成本 `material_block_cost(packet, chunk, first_of_material=True)`。
- 自动段装不满 40% 时不回填手勾；手勾 cap 是硬的。
- 没有自动候选时，不人为留 40% 空预算；手勾可用满。
- 自动候选存在但都放不进 40%：`auto_feasible=False`，手勾可用满；不谎称“自动已保底”。

### 0.5 最终模样

- 合成单块 3000 字手勾 + 700 字自动（单测/e2e 用）：手勾不进，自动进；提示词只说“本步没选中/池里还有”，**不会**说“另有 1 份材料因预算没带进来”。
- 生产分块的手勾长文（每块 ≤300 字）：手勾总量 ≤2277，自动有位置；不会出现“整份不进”的假断言。
- 没有自动候选：手勾可用满 3796；短材料行为不变。
- `RetrievalView` JSON 不再有 `chunk_ids`；前端类型/fixture 不再有；材料卡跳转不受影响。
- 整合失败且本步有 `integration_seq+1` trace：显示失败那条；没有就返回 null、**不渲染整合检索节点**（不拿旧成功冒充）。

#### I：最小实现

```python
@dataclass(frozen=True, slots=True)
class BudgetSplit:
    usable: int
    pinned_cap: int
    auto_feasible: bool


def split_material_budget(
    *,
    usable: int,
    pinned_share: float,
    auto_costs: Sequence[int],
) -> BudgetSplit:
    if not 0.0 <= pinned_share <= 1.0:
        raise ValueError("pinned_share 必须在 [0, 1]")
    pinned_cap = int(usable * pinned_share)
    reserve = usable - pinned_cap
    feasible = bool(auto_costs) and any(cost <= reserve for cost in auto_costs)
    if not feasible:
        return BudgetSplit(usable, usable, False)
    return BudgetSplit(usable, pinned_cap, True)
```

```python
def pinned_selection_cost(harness, round_):
    pinned = set(round_.pinned_materials)
    refs = [ref for ref in round_.materials if ref.material_id in pinned]
    first_seen = set()
    total = 0
    for ref in refs:
        packet = harness.materials.get(ref.material_id)
        chunk = next(c for c in packet.parsed.chunks if c.chunk_id == ref.chunk_id)
        first = ref.material_id not in first_seen
        first_seen.add(ref.material_id)
        total += material_block_cost(packet, chunk, first_of_material=first)
    return total
```
