# 首页 Word/WPS 化 · 左导航壳 + 模板画廊 + 密行

> 拍板（brainstorming bounded）：版式=左导航壳+右内容（多用户以后只加项）；
> 画廊点选即建（切片 2 的 picker 提前落）；行带模板名（后端摘要给，不编）。
> 测试规则：旧用例只改"需求变更"的；新测先红后绿。

**Goal:** 首页一次解决"开个新的"（画廊）+"回去接着写"（密行）；"一份 13 章"字样清零。

## 版式

左 180px 导航（新建/最近/模板库，页内锚点）+ 右内容（画廊横排卡：名+章节数+选中态 →
名输入 → 建项目；密行：标题/版本/日期/模板名/进）。头压成一行小字（原四格条删，
`.summary` CSS 留着——DiscussionTray 共用）。空态沿用"只有一份"：Onboarding 同表单组件。

## 契约与数据流

- 后端：`ProjectSummaryView` +`template_id`/`template_title`（REQUIRED，读行快照零新查询；
  坏行回 STANDARD，memory repo 同款容错）。画廊顺序：builtin 在前、同组按标题
  （标准版第一张，默认高亮不落在第二张）。
- 前端：`NewProjectForm`（画廊+表单，空表退化纯表单，缺省 standard 与后端一致）两处共用；
  `createProject(title, templateId?)` 透传（client 上批已留参）；App 传 templates + 自动进。
- 行上模板名只渲染（无业务判断，旧纪律）。

## 逐文件

- 后端：`dto.py` 摘要两字段；`repositories.py`（两查询+`_template_ref`）；
  `harness.py` 两构造点；`test_dto.py` 三处跟进（需求变更）。
- 前端：`NewProjectForm.tsx`（新）+ `ProjectList.tsx`（重写，删旧内联表单/四格条组件）+
  `Onboarding.tsx`（同表单，文案去 13 章）+ `App.tsx`（传表+签名）+
  `useWorkspaceData.ts`（透传）+ `app.css`（分栏/画廊/选中态，语义色纪律）+ `types.ts`。
- `06-前端.md` 首页节同步。
