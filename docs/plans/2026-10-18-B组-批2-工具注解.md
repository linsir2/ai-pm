# B 组批 2 · 工具 `network_access` 注解实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development（推荐）或
> superpowers:executing-plans 逐任务执行。

**Goal:** 工具声明新增 `network_access` 一个字段，消费者 = 复述卡上的联网授权处（告诉用户
"检索词会发给第三方"）。

**Architecture:** 字段从 TOML 读进 `ToolDefinition` → 装配点透到 `RoundView` →
`OpeningCard` 渲染一句披露。字段集合用守卫测试钉死，把 registry 自己的规矩
（**没有消费者的字段不许加**）变成机器判据。

**Tech Stack:** Python 3.13 · tomllib · React 18 + TS strict · vitest

**Spec:** `docs/plans/2026-10-18-B组-设计.md` §3

## Global Constraints

- **只加一个字段** `network_access`；`read_only` 按"没有消费者不加字段"**砍掉**。
- 端点 / schema / 提示词：不动。DTO 只增字段（`web_search_network_access: bool = False`）。
- 前端文案放组件里（本仓所有界面文案都在组件里，TOML 只管数据）。

def test_network_access_comes_from_the_toml(tmp_path):
    """R：工具会不会把数据发出本机，写在它的 TOML 里（不许在 Python 里猜）。"""
    (tmp_path / "a.toml").write_text(
        'tool_id = "tool.a"\ntitle = "A"\nkind = "a"\nnetwork_access = true\n',
        encoding="utf-8",
    )
    item = TomlToolCatalog(tmp_path).all()[0]
    assert item.network_access is True


def test_network_access_defaults_to_false(tmp_path):
    """缺省 = 不碰外网（保守：新工具默认不外发）。"""
    (tmp_path / "b.toml").write_text(
        'tool_id = "tool.b"\ntitle = "B"\nkind = "b"\n', encoding="utf-8"
    )
    assert TomlToolCatalog(tmp_path).all()[0].network_access is False


def test_web_search_declares_network_access():
    """真目录里联网工具必须声明（复述卡那句披露靠它）。"""
    item = TomlToolCatalog(DEFINITIONS_DIR).all()
    by_id = {entry.tool_id: entry for entry in item}
    assert by_id["tool.web_search"].network_access is True
    assert by_id["tool.attachment"].network_access is False


def test_tool_definition_field_set_is_deliberate():
    """守卫：字段集合钉死——**加字段必须是一次自觉的改动**。

    `registry.py` docstring 明写"没有消费者的字段不许加"（曾经拒掉 9 个字段）。
    这条把那条规矩变成机器判据：谁要加字段，就得在这里解释它的消费者。
    """
    from dataclasses import fields

    assert {f.name for f in fields(ToolDefinition)} == {
        "tool_id", "title", "kind", "requires",
        "max_queries", "max_results", "network_access",
    }
