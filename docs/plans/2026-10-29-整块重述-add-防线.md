## 1. 契约（新增的东西全部有能力出处）

| 契约 | 出处/复用 | 作用一句话 |
|---|---|---|
| `Proposal.overlap: str\|None`（domain 新末字段） | 复用 `allow_manual_override` 的"可选键缺省"序列化先例 | **草案当时对着当时文档的机械判定快照**（"dup/total"），随草案落库；旧轮无键 → None，回放不漂 |
| `_strip_eid_citations(text)`（application/assembly.py） | 复用 `_ENTRY_ADDRESS` 清洗先例（L13） | 剥纯 E 号括号：正则只认"括号内除 E 号 token 外没有别的"，`（见 E12）`不碰；逐行处理保多行 |
| `_strip_list_marker(line)` | 新（3 行正则） | 剥行首 `- `、`•`、`1. `——行等比对用，不碰原文 |
| `_existing_lines(document)` | `_existing_content` 的行级孪生（同一个 label 公式，两版同文件共置） | `(label, 归一化行)` 集合，给 overlap 只读判据 |
| `_overlap_note(text, label, lines)` | 新 | 非空行≥2 且 dup×2≥total → `"dup/total"`，否则 None；仅 ADD |
| `_proposal_view.warning` 合成 | 既有 ⚠ 通道（ScopeGuard 在用）+ 新字段 `ProposalView.overlap` | 人话进 warning，字段给前端判默认勾选 |
| gaps 行 | 既有缺口行通道 | "本轮有 N 条提案与字段已有内容重叠（已默认不勾，看清再勾）" |
| integrator.md 静态区 4 行硬规矩 | md 内已有"补一条硬规矩"先例；不动 `$limits`（有相等断言） | 教模型：提案是增量动作；改写用 replace；既有行不要重提；编号不进正文 |
