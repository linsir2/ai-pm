### 0.2 问题 2：`conflict` 从来没人写（不是没做卡片）

卡片**做了**——它是问卷卡里的一类题，不是另一张抽屉：`QuestionKind`（`gap/conflict/decision`）、
`QuestionView.kind`、前端 `QUESTION_KIND_TEXT`（缺口/矛盾/决策）、`q--conflict` 样式、
抽屉标题右侧「N 个矛盾要你拍板」徽标、`document/status.ts` 里 `conflict|decision` 算"要你拍板"、
`gap` 算"还差信息"（合并成一张问卷也是作者定的口径："矛盾和缺失信息不都是提问吗"）。

缺的是**上游从不给这个字段填 conflict**：

| 数据 | 结果 |
|---|---|
| `edge-contradiction` 的 15 道题 | **8 道根本没写 `kind`** → 被 `schemas.py:104` 的默认值 `"gap"` 静默吞掉；写了 7 道：`decision` 1 / `gap` 6 |
| P10 真跑两轮 54 道题 | `gap` 46 / `decision` 8 / **`conflict` 0** |

两条结论：① 默认值把"忘了写"和"判断成 gap"混成一种；② 在模型眼里，两侧互斥的补救天然是

def target_from_label(label: str) -> Target | None:
    """`Target.label()` 的反函数（2026-09-29 P11 C1）。

    为什么放在领域里：`label()` 的形态是**领域词汇表**的一部分（卡片、提示词、导出的 s11 条目都用它），
    反函数跟它住一起才不会两边漂；`Target.__post_init__` 的校验顺便把"章节不存在"挡住。

    认不出来就返回 `None`——调用方（`deferred_from_open_items`）回落 `s11`，绝不猜。
    """

    text = label.strip()
    if not text:
        return None
    if text == "preference":
        return Target.preference()
    head, _, field = text.partition(".")
    section_id, slash, slug = head.partition("/")
    if not section_id or (slash and not slug):
        return None
    try:
        return Target.body(section_id, feature_slug=slug or None, field=field or None)
    except DomainError:
        return None
```

> 说明：`Target` 的构造会抛 `TargetShapeError` / `UnknownSection`，都是 `DomainError` 的子类；
> 这里一并吞掉换 `None`（**形状不认识**），与"字段表里没有这个名字"（内容层，`_kind_for` 管）分得很清。
> `domain/shared/target.py` 需要 `from pmstudio.domain.shared.errors import DomainError`（若尚未导入）。

@dataclass(frozen=True, slots=True)
class OpenItem:
    """s11 未决条目的解析结果（P11）。

    比三元组多一个 `target_label`：**去处要跟着内容走**——没有它，问回来只能回到 s11，
    答案也就永远落不回正文（真跑里四条答案就是这么蒸发的）。
    """

    title: str
    consequence: str
    blocking: bool
    target_label: str | None = None


#: 去处标记：写在条目**末尾**，与旧格式向后兼容（老条目没有它就是 None）
_TARGET_MARK = re.compile(r"〔去处：(?P<label>[^〕]+)〕\s*$")


def parse_open_item(text: str) -> OpenItem | None:
    stripped = text.strip()
    target_label: str | None = None
    mark = _TARGET_MARK.search(stripped)
    if mark is not None:
        target_label = mark.group("label").strip()
        stripped = stripped[: mark.start()].rstrip()
    match = _OPEN_ITEM.match(stripped)
    if match is None:
        return None
    return OpenItem(
        title=match.group("title"),
        consequence=match.group("consequence"),
        blocking=stripped.startswith(BLOCKING_MARK),
        target_label=target_label,
    )
```

## 4. 数据流（改完之后的走向）

```
题（有去处）
  └─ 用户跳过 / 超限 → s11 条目「〔未决·阻塞〕标题（未决定…；跳过后果：…）〔去处：s5/x.field〕」
        └─ 下一轮问回来：target = s5/x.field（认不出才回落 s11）
             ├─ 去重：与模型新出的题**同去处同问法**才撞（近义措辞仍可能重复，见 §6）
             └─ 用户答了 → 答案编号 E#
                  ├─ 被整合者引用 → 整合者写正文
                  └─ 没被引用 → 机械落地「用户已定：…」到 **s5/x.field**（去处是 s11 的才跳过）
                  └─ 同时：机械 remove 撤下那条 s11 条目（P9 不变）
```

一句话：**s11 从"一个只有题面的黑洞"变成"一条能回到原处、也能把答案送回正文的待办"。**
