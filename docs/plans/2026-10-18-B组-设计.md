## 4. 批 3 · L2/L3/L4 容量水位 ＋ `recent()` 时间序修复

**更正我上一轮的设计（重要）**：`observations.created_at` **不能加**——

**改用**：`observations.round_id` → `JOIN rounds.created_at`（`rounds` 本来就有时间戳），

**顺带挖出的真 bug**：真库 id 形如 `obs-1-…` / `obs-9-…` / `obs-10-…`，而
`recent()` 用 `ORDER BY id DESC` —— **字典序**，`obs-9` 排在 `obs-10` **前面**，
"最新在前"不成立（46 行里只有 23 个 distinct `source_ref`，去重后留哪条是随机的）。
本批用 JOIN 把它一并根治。

**要加**：

## 5. 批 4 · 记忆命中：现算 ＋ 遥测 ＋ **界面标**

**更正我上一轮的设计（重要）**：原方案把"（久未使用）"标进**提示词**。新证据两条：
① `render_memory` docstring 明令**不渲 id**（M6f 真跑：席位把行首 `mem…` 当出处编号写进
`evidence_refs` → **整趟席位判失败**）；"菜单里放什么，模型就点什么"；
② 把仍然有效的旧教训标成"久未使用"，可能让模型**误弃**它——**负价值风险**。

**所以标到界面**（作者 2026-10-17 拍板）：记忆抽屉里给"久未使用"标签，

  `unused_entries(entries, cited_by_round: Mapping[str, frozenset[str]], *, window: int) -> frozenset[str]`

  （`memory.py` docstring 早就写着"**不存计数器**：命中与否现算"。）
- `MemoryEntryView.unused: bool = False`（`dto.py:845`，只读投影）。
- `use_cases` 构建 `WorkspaceView` 时算一次（引用集来源 = 已有 `assembly.cited_eids`，
  **不新造**；窗口 `MEMORY_USAGE_WINDOW = 10`）。
- `MemoryDrawer.tsx`：`unused` 为真时加一个 `tag`「久未使用」。
- `scripts/telemetry.py` 加记忆命中表（每条 × 最近 N 轮命中次数）。
- `.codex/docs/设计/02` 补口径：窗口 = 10；**标记只在界面**，不进提示词（附理由）。

## 6. 批 5 · 检索向量召回（阶段 2）

**外部库（已联网核实）**：`sqlite-vec` 0.1.9（MIT/Apache-2.0，`pip install sqlite-vec` →
`conn.enable_load_extension(True)` + `sqlite_vec.load(conn)`，需 SQLite ≥3.41；本机 3.51.0，
`enable_load_extension` 实测可用）；`fastembed` 的 `BAAI/bge-small-zh-v1.5`
（**dim 512 / MIT / 0.09GB / ONNX 无 torch**，`TextEmbedding(model_name=…, lazy_load=True)`、`.embed()`）。

**要加**：`embedding.py`（`Embedder` 协议 + `FastEmbedEmbedder`）；
`material_chunks_vec`（vec0，`chunk_id` 主键 + `FLOAT[512]`）；`connect()` 载扩展；
`migrate` 扩回填（幂等）；`_write_chunks`/`_drop_index` 同事务写/删向量；
`SqliteHybridRetriever`（FTS5 topK + KNN topK → RRF）；`container.py:292` 换一行。

**关键决策（本轮唯一架构抉择）**：ONNX 推理**不能落在写事务里**（一次上传 10 块 × ~20ms
= 200ms 持写锁，是基线写操作的百倍，与 P5 系列刚拿下的成果正面冲突）。
采纳 **(c′)**：主事务提交后，另开**小事务**只写该材料的向量（embed 在锁外算）；
崩溃窗口由**已有**的幂等回填兜底。

**降级（模型不可用不许判死）**：扩展载不了 / 模型下载失败 / 推理抛 → 记一行 warning，
检索退回纯 `SqliteFtsRetriever`，上传与检索**都成功**。
