### T1 模板 schema（判据声明化；本任务零行为变化——新字段只被 validate + 新 helper 读）

`template.py` 新增（exact）：

```python
@dataclass(frozen=True, slots=True)
class MinEntries:
    count: int
    kind: BlockKind | None = None   # 如 acceptance；None = 不挑种类

# TemplatedSection 新增：
    min_entries: MinEntries | None = None
    coverage: int | None = None     # 缺省走 ROLE_COVERAGE_DEFAULT
```

- `template_from_dict`：`min_entries` 接受 int（→`MinEntries(count)`）或 `{count, kind?}`；kind 串必须 parse 成 `BlockKind`，否则 `BadTemplateDefinition`；`coverage` 必须 ≥1 整数。
- `validate()` 加三断：① `min_entries` 只许出现在 BACKBONE/PLAIN/STEPS/DECISION（FEATURE/OPEN/VERSION 上声明 = 无意义，直接炸）；② `coverage` 不许出现在 VERSION（版本章永不参判）；③ `count ≥ 1`（0 = 写了等于没写，炸）。
- 新增方法（exact 签名）：
  - `check_target(section_id, feature_slug, field) -> None`：成员三闸，抛与今日同类的三个错，消息见 §3（带模板名）。
  - `min_entries_for(section_id) -> MinEntries | None`
  - `coverage_minimum(section_id) -> int`：声明值；缺省规则——VERSION 章调了就炸（validate 已拦）；有槽 → `len(slots)`；FEATURE → 2；STEPS/DECISION/OPEN → 2；BACKBONE → min count（无声明 → 1）；PLAIN → 1。
  - `blocking_sections() -> frozenset[str]`：FEATURE 锚点 ∪ 有 min 声明 ∪ 有槽。
  - `role_of(section_id) -> TemplateRole | None`；`steps_section()/decision_section() -> SectionId | None`（首个该 role）。
- `ROLE_PRESENCE_LABEL = {STEPS: "主流程", DECISION: "技术决策"}`（domain 常量，替代 `KIND_PRESENCE` 的 label 列）。
- TOML：`standard.toml` 13 章加 `min_entries`（s1:1/s2:2/s3:1/s4:2/s10:1/s12:`{count=1, kind="acceptance"}`，coverage 全缺省——缺省规则逐字复刻现行值，见下表）；`light.toml` 加 s1:1/s2:2/s4:2。
- 缺省复刻验证表（standard，必须逐字成立，否则 TOML/规则错）：s1:1 s2:2 s3:1 s4:2 s5:2 s6:2 s7:2 s8:6 s9:2 s10:1 s11:2 s12:1，s13 排除。
- `api/schemas.py`：`TemplateSectionRequest` 加 `min_entries: int | dict | None`、`coverage: int | None`；`use_cases.CreateTemplate` 透传；`template_from_dict` 同一校验（两种入口同一套，不各写一遍）。
- DTO：`TemplateSectionSchemaView`/`TemplateView` 投影新字段（`GET /templates`、`GET /schema.templates` 可见）。
