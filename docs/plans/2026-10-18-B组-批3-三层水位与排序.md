# B 组批 3 · L2/L3/L4 容量水位 ＋ `recent()` 时间序修复 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development（推荐）或
> superpowers:executing-plans 逐任务执行。

**Goal:** ① 修掉 `recent()` 的**字典序** bug（`obs-9` 排在 `obs-10` 前，"最新在前"不成立）；
② 给 L2/L3/L4 三层一个**可测的水位**（超水位才在提示词里照实说"更早的待复核"）；
③ 把"三层生命周期"写成口径与遥测，**一行都不删**。

**Architecture:** 时间源用 `observations.round_id → rounds.created_at`（**不加列**：
`created_at` 是上一轮"死字段清理"故意删的，`database.py:36` 的 `DROPPED_COLUMNS` 里有据）。
水位是渲染层常量 + 一行报数；生命周期是**口径 + 遥测**，不是删除逻辑。

**Tech Stack:** Python 3.13 · sqlite3（WAL）· pytest

**Spec:** `docs/plans/2026-10-18-B组-设计.md` §4

## Global Constraints

- **不自动删任何记忆**（`07 §7.4`）。三张表本批**一行都不删**。
- **不重建 `observations.created_at`**（那是撤销已拍板的清理）。
- 端点 / DTO / schema / 前端：零改动。
- `recent()` 的**去重语义**（同 `source_ref` 留最新）不变，只改"最新"的**判据**。

- [ ] **Step 3: 最小实现**

```python
        resolved = require_owner(owner)
        # 时间源 = 该观察所属轮次的 `created_at`——**不加列**（`created_at` 是上一轮
        # "死字段清理"故意删掉的，见 `database.DROPPED_COLUMNS`）。`LEFT JOIN` 兜住
        # 老库/半截轮里指向不存在轮次的行（`COALESCE` 把它们排到最后，不许炸）。
        rows = self._connection.execute(
            "SELECT o.*, COALESCE(r.created_at, '') AS round_at"
            " FROM observations o LEFT JOIN rounds r ON r.round_id = o.round_id"
            " WHERE o.project_id = ? AND o.owner_id = ?"
            " ORDER BY round_at DESC, o.id DESC",
            (str(project_id), str(resolved)),
        ).fetchall()
        # 同 source_ref 去重：**已按时间序**遍历，第一次遇到即最新——不再二次排序
        #（二次按 id 排正是那个字典序 bug 的来源）。
        seen: dict[str, sqlite3.Row] = {}
        for row in rows:
            seen.setdefault(row["source_ref"], row)
        ordered = list(seen.values())
        if limit is not None:
            ordered = ordered[:limit]
        return tuple(self._row_to_obs(row) for row in ordered)
```

`_row_to_obs` 只读它认得的键，多出来的 `round_at` 不影响它。

**顺带修模块 docstring**（第 1 行）：`"""L2 观察的 SQLite 仓储：CRUD + LIKE 搜索 + 去重（…）。"""`
——`LIKE 搜索` 已随 `search`/`get` 删除（2026-10-17 C1），改成
`"""L2 观察的 SQLite 仓储：写入 + 最近观察（按轮次时间倒序、按 source_ref 去重）。"""`
