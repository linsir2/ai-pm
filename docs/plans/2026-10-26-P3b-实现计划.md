# P3b 实现计划：多 worker 真安全 + 有界研究

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.
> 本计划分 **P3b-0 债务/并发** 与 **P3b-1 研究** 两段；P3b-0 未过验收不得开 P3b-1。
> 每个任务按 **R → I → P → R2** 四门（见 `2026-10-24-检索重构-实施计划.md` §10.1）。

**Goal:** 在共享 SQLite 的多 worker 部署下，让轮内动作与项目级研究各自只有一个 DB lease 持有者；随后交付项目级有界 agentic 研究（≤6 轮 / ≤12 调用 / ≤5 来源）、只读结果和来源卡显式挂当前轮。

**Architecture:** 两个长动作（`RoundRunner` / `ExplorationRunner`）在进入模型/网络前获取各自行上的 DB lease，后台心跳续租，`save` 用 lease token fencing；`WebRequest` 保持 5 状态，`approved` 为 claim，名额在同一个 UoW 内重算，超额走逐条恢复。研究复用现有 `Exploration` 容器、`ExplorationRunner` 项目锁、`run_tool_loop`、Tavily/抓页/解析/材料入库/E 号路径；不新建研究表、不复用 KeepCandidate。

**Tech Stack:** Python 3.13 / FastAPI / SQLite(WAL) / LangGraph / Pydantic / React 18+Vite+TS / pytest / vitest。

## 0.2 评审后硬约束（覆盖后文，必须先满足）

- **start 的 lease 绑定**：`RoundRunner.run` 在 `ainvoke` 之前把**同一个可变 `LeaseScope` 对象**放进 contextvar；`StartRound.create` 在**同一个 UoW** 内 INSERT round 并 `acquire_new(round_id)`，绑定 token；`node_start` 只负责 create，不再二次 acquire；`node_analyze` 用同一 scope token save。LangGraph 节点 context 会复制，重新 set 在 `node_analyze` 不可见。必须测“start token 在 analyze 的 save 可见”和“create 后无未租约窗口”。
- **Lease SQL 必须带用户 `owner_id`**（与持有者 `lease_owner` 分开）；`save` 同时校验 `kind/target_id/user_id/持有者/token/expires_at>now`。release 是尽力而为，0 行不映射 409；只有 owner/token 不匹配或已过期才算 lost。心跳遇 `database is locked` 先短退避重试，不能当 lost。未知 target：404；被占：409。
- **Opening 名额算法**：`used_before=` 库里 approved/done/failed 数；`new_approved=` preview 新批准数；`available=max(0, limit-used_before)`。
  - `used_before > limit` 且存在 approved → 409 recovery；
  - `used_before >= limit` 且 `new_approved > 0` → 422 让用户减勾/先恢复；
  - `used_before < limit` 且 `new_approved > available` → 422；
  - 其余可开场；只执行 `existing approved + new approved`，新批准数不超过 available；
  - `used_before >= limit` 且无 approved、无新批准 → 开场但零 web。
  `execute_approved` 在 `used>=limit` 不抛 422，只跳过自动批准/超额 approved；后续模型步必须能继续。
- **恢复的“放弃”用 `approved→rejected`**（新增 `Round.cancel_approved_web_request`，带 note；“rejected 不计入 used”），不是 failed。恢复执行允许一次临时超额；恢复只处理 `approved` 且 `used>limit` 的请求。恢复后 opening 必须能成功。
- **SkipSeat**：`round_skips` 增加 `pass_index`；`RoundRepository.get`（含 `_review_one` fresh read）把控制行应用到 `skipped_seats`（集合，幂等），**不把合成 USER_SKIPPED 写进 Round.dropped**；DTO 视图合成留痕；`SkipSeat` 不写 Round；`_review_one` attest 前重读，迟交丢弃。get→save→get 不复制留痕。
- **RunSeatRound 的 E/观察写入**：`assign_opinions`、`evidence_writer.save`、`_extract_and_store_observations` 前必须 `LeaseScope.ensure_held()`，或与 fenced round save 同一 UoW；失租后不得新增 E/observation。
- **Exploration create/retry 的租约只 acquire 一次**：`RunInquiry.create` / `StartWebResearch.create` 在同一个 UoW 内 INSERT 并写 lease（token=1），返回绑定好的 token；`ExplorationRunner.start` **不再 acquire**，直接 bind 并执行。`RetryExploration.resume` 在同一个 UoW 内把行置 RUNNING 并 acquire，避免无租约窗口；`runner.retry` 不再 acquire。`clear_stale` 只清 lease 过期的 running，活租约不清；唯一索引冲突转 `ExplorationBusy`。
- **M8 非 runner 写**：`KeepCandidate`/`DismissCandidate`/`clear_stale` 是短控制写；仓储 fence 对“非 running 或 force 绑定”显式豁免，或这些用例 force_acquire+bind；不能一律 409。
- **多 worker 测试注入**：新增 `tests/support/uvicorn_app.py` 测试专用 factory + 跨进程文件/套接字 gate（不用 asyncio.Event 跨进程；不用 sleep 碰运气），支持 `gateway`/`web_search`/`fetcher` 注入；只被 smoke/test 使用，生产 `build_app` 不加假开关。Task 2/7 用它做同轮竞争 + SIGKILL。
- **WAL 版本门禁**：Task 7/13 用现有 `database.wal_reset_vulnerable()` 判据（不是裸版本号比较）；Task 7 改 `backend/Dockerfile`/base pin 或安装修复版；`docker compose build` 后容器内断言；不满足不得宣称多 worker 可上线。
- **`KeepSimInquiry`**：用 `RoundRunner.short_action(round_id, ...)`（租约内、非图）保留 `KeepSimResult` 回包；不要硬塞进 `RoundState`。
- **`web_research` 材料隔离**：`StartRound._pick_materials`、自动检索段、`AttachMaterials`、`MaterialPicker`、搜索命中都必须排除 `web_research`；`MaterialLibrary` 保留只读展示但禁用挂载；来源卡走独立 attach。
- **研究来源 E 可引用**：`Round.research_sources` 的 E 必须并入 analyzer/seat/integrator 的 allowed E 集合；否则模型看见 E 却会被 `known_eids` 过滤。
- **来源生命周期**：`web_research:{url}|{sha}` 独立材料命名空间（不与 P3a `web:{url}` 撞）；`material_references` 扫描 `Round.research_sources` **和未挂轮的 `Exploration.research.sources`**；删除/重解析冻结；向量字符帽与 `web_search` 同口径；完整正文只在材料库。
- **研究启动是同步的**：`POST /projects/{id}/research` 走 `ExplorationRunner.start_research`，请求内 await `execute`，返回最终 `ExplorationView`（done/failed）；不新增后台任务/任务表。运行态只来自另一个客户端/重读。
- **来源卡单一文本**：`source_card_text(source)` 同时用于 `ledger.record` 和渲染；预算超限按整卡跳过并写“还有 N 条”，不截断卡片；E 文本=卡片。
- **DTO/请求体**：`ResearchPacket{basis,findings:[{text,refs:S*}],open_questions}`；`ResearchView{findings,sources,open_questions,notes}`；`ResearchRequest{topic:1..500}`；`AttachResearchSourcesRequest{exploration_id,eids:1..5}`；响应分别为 `ExplorationView`/`RoundView`；404/409/422 写进 OpenAPI 测试。
- **UI**：第 4 个“研究”页签在 `round=null` 可用；`mode=opening` 与现有页签一样不可达（明确写进验收）；InboxTray 只接 inquiry；`onStartWebResearch` 与 M8 `onStartResearch` 分开；所有 research/retry/abandon/attach 动作带项目 guard。
- **Task 顺序/命名**：Task 8 创建 `application/research.py`（常量/值对象/**source_card_text**）；Task 9 创建 `infrastructure/tools/research_tools.py`（transient 值对象 `ResearchHit`）；Task 10 Modify `application/research.py` 加用例；Task 11 只消费 `source_card_text`/加 Round 字段。

### 非目标

- 不做 start 幂等键（同一输入双击仍可能生成两轮；这是现有行为，P3b 不扩）。

```

HTTP / SSE ─────────────▶│ RoundRunner (per app)        │
                         │  local _running_rounds       │
                         │  DB lease(round_id) + token  │
                         └──────────────┬───────────────┘
                                        │ acquire / heartbeat / release
                                        ▼
                         ┌──────────────────────────────┐
                         │ rounds.lease_owner/expires/  │
                         │ token  (SQLite row)          │
                         └──────────────┬───────────────┘
                                        │ save() fence
                                        ▼
                         ┌──────────────────────────────┐
                         │ RoundRepository / Round      │
                         └──────────────────────────────┘

HTTP ───────────────────▶ ExplorationRunner (per app)
                         │ local _running_projects
                         │ DB lease(exploration_id)
                         └──────────────┬───────────────┘
                                        ▼
                         explorations.lease_owner/expires/token
                         UNIQUE(project_id) WHERE status='running'
```

### 1.1 轮内动作时序

```
POST /opening|answers|decision|...
  → RoundRunner.run
  → acquire round lease (token=n) ──失败→ 409 round_busy
  → 进入 LangGraph（模型/联网）
  → repository.save 校验 token=n；失租→整笔 UoW 回滚 + 409 lease_lost
  → finally release；本进程 cancel 仍然只取消本地 task
```

### 1.2 研究时序

```
POST /projects/{id}/research {topic}
  → ExplorationRunner.start_research
  → UoW#1: Exploration(WEB_RESEARCH,RUNNING,scope=TOPIC) + acquire exploration lease
  → run_tool_loop(purpose=web_research, specs=web_search/fetch_url)
       toolbox: sources≤5, URL 去重, attempts≤12（含失败）, 不碰 DB
  → sources==0 → fail；不落材料/E
  → ResearchSynthesizer.call_structured(ResearchPacket, refs=S1..S5)
  → 机械过滤/映射
  → UoW#2 (fresh ledger): 每来源一个 E；materials.put；complete_research
  → commit 后 vectors.write；publish exploration.updated
```

### 1.3 研究来源挂当前轮

```
结果卡「挂到当前轮」→ POST /rounds/{id}/research-sources
  → RoundRunner(round lease)
  → UoW: Round.attach_research_sources(exploration_id, eids)
  → round.updated
  → 下一步 prepare：render_research_sources（来源卡，一条来源一个 E）
```

## 2. 数据模型与契约

### 2.1 Lease

```python
# domain/shared/lease.py
class LeaseKind(StrEnum):
    ROUND = "round"
    EXPLORATION = "exploration"

@dataclass(frozen=True, slots=True)
class LeaseToken:
    kind: LeaseKind
    target_id: str
    user_id: str
    holder: str
    token: int
    expires_at_ms: int
```

- `application/ports.py`:
  ```python
  class LeaseStore(Protocol):
      def acquire(self, kind, target_id, user_id, holder, now_ms, ttl_ms) -> int | None: ...
      def renew(self, kind, target_id, user_id, holder, token, now_ms, ttl_ms) -> bool: ...
      def release(self, kind, target_id, user_id, holder, token) -> None: ...
      def force_acquire(self, kind, target_id, user_id, holder, now_ms, ttl_ms) -> int: ...
  ```
- `LeaseScope`（`application/lease.py`）持有当前 `LeaseToken`；`RoundRepository.save` / `ExplorationRepository.save` 从 contextvar 取 token，不把 token 放进 `Round`/`Exploration` 聚合。
- `LEASE_TTL_SECONDS=90`、`LEASE_HEARTBEAT_SECONDS=30`；心跳失败/失租 → `RoundLeaseLost` / `ExplorationLeaseLost`（409），不走 `fail`，不发 `round.updated`。
- SQL（两张表同形）：
  ```sql
  ALTER TABLE rounds ADD COLUMN lease_owner TEXT;
  ALTER TABLE rounds ADD COLUMN lease_expires_at INTEGER;
  ALTER TABLE rounds ADD COLUMN lease_token INTEGER NOT NULL DEFAULT 0;
  -- explorations 同三列
  ```
- 获取：`UPDATE ... SET lease_owner=?, lease_expires_at=?, lease_token=lease_token+1
  WHERE id=? AND owner_id=? AND (lease_owner IS NULL OR lease_expires_at <= ?) RETURNING lease_token`。
- 续租/释放必须带 owner+token+未过期；0 行 = 失租。
- 过期接管不清理旧任务；旧任务的 `save` 因 token 不匹配失败。`abandon` 用 `force_acquire`。
- `round_skips`：
  ```sql
  CREATE TABLE round_skips (
    round_id TEXT NOT NULL, owner_id TEXT NOT NULL,
    seat_id TEXT NOT NULL, pass_index INTEGER NOT NULL,
    reason TEXT NOT NULL, source TEXT NOT NULL,
    requested_at INTEGER NOT NULL,
    PRIMARY KEY(round_id, seat_id)
  );
  ```

### 2.2 `WebRequest`（保持 5 态）

- 状态：`proposed/approved/rejected/done/failed`；`approved` 是 claim，执行由唯一 round lease 串行。
- `DecideWebRequest` 的 `used` 在 claim UoW 内 fresh read 重算；`used >= limit` → 409，不批准。
- `execute_approved`:
  - `used < limit`：自动批准 seat/integrator 到名额；执行 approved。
  - `used == limit`：不自动批准；仍执行 already approved（它们已计入 used，不会新增）。
  - `used > limit`：不自动批准、不抛 422、不执行超额 approved；它们留给逐条恢复。
- `SubmitOpening`：工具检查移到 preview 之后；stale DONE/FAILED id no-op；`used>limit` 且存在 approved → 409 recovery；`used>limit` 但只剩 done/failed → 继续但零 web；`used>=limit` 时有新批准 → 422 让用户减勾。
- 逐条恢复：
  ```text
  POST /rounds/{id}/web-requests/{rid}/recovery
  body {"action": "execute" | "abandon"}
  ```
  - 只允许 `approved` 且 `used > limit`；`execute` 允许一次临时超额，`abandon` 走 `approved→rejected` + note（不计入 used）；走 `RoundRunner`，网络 UoW 外。
  - 新增 `RecoverWebRequest` command / graph node / API；`RoundView` 返回。

### 2.3 研究数据

```python
# domain/exploration/research.py
@dataclass(frozen=True, slots=True)
class ResearchSource:
    eid: EvidenceId
    material_id: str
    title: str
    url: str
    excerpt: str          # 来源卡正文，≤800 字

    finding_id: str
    statement: str

@dataclass(frozen=True, slots=True)
```

- `ExplorationKind.WEB_RESEARCH="web_research"`；`ScopeKind.TOPIC="topic"`；`Exploration.research: ResearchReport | None`；`scope.text=topic`（1..500）。

- Agent packet：`ResearchPacket{basis: str, findings: [{text, refs: ["S1"..]}], open_questions: [str]}`；`findings`/`open_questions` 可空。
- DTO：`ResearchView{findings:[{finding_id,text,refs}],sources:[{eid,material_id,title,url,excerpt}],open_questions,notes}`；`ExplorationView.research: ResearchView|None`。
- 序列化 payload 新键 `research`；老行缺失 → `None`；`ExplorationView.research: ResearchView | None`。
- `RoundResearchSource`（`domain/round/research.py`）：
  ```python
  @dataclass(frozen=True, slots=True)
  class RoundResearchSource:
      exploration_id: str
      eid: EvidenceId
      material_id: str
      title: str
      url: str
      excerpt: str
  ```

  `Round.research_sources`、`attach_research_sources`；DTO `RoundView.research_sources: tuple[{exploration_id,eid,material_id,title,url,excerpt},...]`；可挂载 step 复用 `AttachMaterials` 集合并显式排除 `awaiting_confirm`。

### 2.5 新动作契约

- `RoundRunner.short_action(round_id, fn) -> T`：获取 round lease → await `fn()` → release；用于 `KeepSimInquiry`（保留 `KeepSimResult`）和 `AttachResearchSources`（返回 `RoundView`）。不把结果塞进 `RoundState`；不新增图节点。
- `RecoverWebRequest`（图命令）：
  ```text
  kind="recover_web_request"
  request_id: str
  recovery_action: Literal["execute","abandon"]
  POST /rounds/{id}/web-requests/{rid}/recovery
  → RoundView; 404 unknown; 409 非 approved/未超额/终态/lease
  ```
  `execute` 临时超额执行一次；`abandon` 把 `approved→rejected` + note。
- `AttachResearchSources`（short action）：

## 6. 风险与未决

| 风险 | 缓解 |
|---|---|
| SQLite WAL + 多进程写 | 短 UoW；写只走 `BEGIN IMMEDIATE`；用 `wal_reset_vulnerable()` 门禁并 pin 修复版；不承诺多主机 |
