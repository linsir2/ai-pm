- [ ] **Step 2: 写机械校验**（gold ordinal < 该文档块数；points 每条非空且 ≤50 字；question 与 points 无逐字包含——含了等于送分）

```python
def check_item(doc_blocks: int, item: dict) -> list[str]:
    errs = []
    if not item.get("gold") or any(not isinstance(o, int) or o >= doc_blocks for o in item["gold"]):
        errs.append(f"gold 非法：{item.get('gold')}（该文档 {doc_blocks} 块）")
    if not item.get("points") or any(not p.strip() or len(p) > 50 for p in item["points"]):
        errs.append("points 空或超长")
    for p in item.get("points", []):
        if p.strip() in item.get("question", ""):
            errs.append(f"要点被问题逐字包含（送分）：{p[:20]}")
    return errs
```
