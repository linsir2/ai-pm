**Goal:** 右列改成 Codex 式（页签 + 常驻进度头 + 单线程流 + 问卷/草案 inline 卡 + 底部 composer），
底条拆除、文档列通底并缩小占比。

**Architecture:** 只搬调用点不搬逻辑。抽屉去悬浮纯 CSS（`.loop > .drawer` static，
DOM 顺序即流顺序）；composer = BottomStrip 左右两半整体搬入 loop 底；shell 删 foot 行。

**Tech Stack:** React 18 + TS strict + vitest(jsdom) + 现有 tokens。

**Spec:** `.codex/docs/设计/06-前端.md` §2（同步更新） + 本计划。
