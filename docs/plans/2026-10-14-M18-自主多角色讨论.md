# M18 · 自主多角色讨论 + 综合层 实施计划

> 拍板（2026-10-14 问卷×2）：自主多角色（全自动跑 N 轮）→ 多角色同场可中途加入 →
> 三页签一条龙 → 定轮数跑满即停（默认 3，上限 5）+ 人在看/随时参与/想停就停 →
> 每轮综合 → 新上限（rounds≤5/panel≤4/turns≤30）→ 确定性轮转+综合（无独立主持人调用）→
> 边界停+轮内可中断 → 并行+完成序 → 失败保留已落 turns → 默认 3 固定角色×3 轮。
> 依据：ArgsBase（硬规则 turn-taking + Analyzer 四块 + 单动作/轮）/ Amicus（phase 边界停、
> Directive/Opinion 双通道、open questions 一等产出）/ Perspectra（@拉人、后端富前端简、
> broadcast 只适合搜料）/ eddi（静态 choreography、枚举 moves、三件套终止、招募下一轮生效）/
> AG-UI（pending 中断挡新输入）/ Magentic-UI（co-tasking、步骤边界暂停）。
> 测试规则：旧用例只改需求变更的；新测先红后绿。

**Goal:** 讨论区从"用户一句→AI 一句"变成：开跑后多角色自己讨论 N 轮、每轮出综合、
用户随时插话/拉人/停止，最后总结成卡（唯一回流不变）。

**Spec:** `.codex/docs/设计/02-编排与数据.md` 新 §（M18 + T2'/T4' 修订） +
`.codex/docs/设计/06-前端.md` 讨论区节重写 + 本计划。`07` 不动（讨论仍不读 M6）。

## 不做

投票/裁决、mind map、@指定单回、what-if、thread-branching、token 账单页、
综合喂 assemble（卡片只读 turns 历史）、收敛自动停（黑箱）、独立主持人 LLM 调用。

## 数据模型（`domain/discussion/thread.py`，只加不改）

- `+Participant{role_id, role_title, joined_round}`；`Discussion.participants`
  （`start` 建；旧行缺键读回回落，单成员 = 今天，无迁移）。
- `Turn` 加 `author: str = "assistant"`（agent turn 写 role_id，用户 turn 写 `"user"`）。
- `+RoundSummary{index, agreed, disagreed, open}`（tuple[str]）；`Discussion.summaries` 只增；
  `append_agent_turn()` + `append_summary()`。
- T2'：用户 turn 仍成对原子；agent turns 按（round, author）有序追加，失败不记。
  T4'：`rounds≤5、panel≤4、turns≤30`。`say_pair/close/keep/dismiss` 原样。
- `JoinPanel`：open 校验 + 未在场 + 未满 4 + `joined_round=下一轮`（不追补）。

## 编排与端点

- `StartDiscussion`：`role_id` → `role_ids[1..4]`（问卷锚点 path 由前端包成单元素）；
  `question`/`findings` 对整个 panel 生效。
- 新 `RunPanelRound(discussion_id)`：本轮在场者（`joined_round ≤ 本轮`，本轮=`len(summaries)+1`）
  **gather 并行** `discusser.say`（history/known/validation 与 SayToThread 同一路，提共享 helper；
  M16 lenient 照常）→ 逐条落库+publish（直播）→ **synthesis** 调用 → 落库+publish+返回 view。
  失败：已落 turns 保留（自包含合法），本轮停、无综合，重试补剩余发言者。
  `turn_slot` 唯一化（`s{base}_{role}`）。
- 新 prompt `discussion_synthesis.md` + packet schema + definition（`purpose=discussion_synthesis`）：
  输入本轮 turns + 历史综合，输出三组 bullets；不开新观点、不编 E、无 refs 字段。
- `SayToThread`（插话）/`AssembleCards`（输入不动）原样；中途拉人 `JoinPanel`。
- 停止：边界停=不再调下一轮；轮内中断复用 `RoundRunner` 注册表模式
  （新 `DiscussionRunRegistry` + `DiscussionCanceller` port + `POST .../abort-run`）；
  重入调 run-round → `DiscussionBusy` 409（`RoundBusy` 同构）。
- 插话并发：前端排队（轮次边界自动发出，pending 显"等本轮说完"），不动后端。
- 端点：`POST /discussions`（换 `role_ids`）、`POST /discussions/{id}/run-round`、
  `POST /discussions/{id}/join`、`POST /discussions/{id}/abort-run`。
- `ThreadView` += `participants`、`turn.author`、`summaries`；序列化旧行缺键回落（M12 纪律）。

## 前端

- 开跑 panel（新线程）：主题框 + 角色多选（3 固定 + 领域席位，默认全选 3 固定）
  + 轮数 1–5（默认 3）+ 「先跑一轮调研」保留 → [开跑]（建线程后自动循环 run-round）。
- Live：turns 按轮分组 + 每轮综合三组；进度"第 X/N 轮"；[停止]（调 abort）/[插一句]/
  [拉人进来]/[再跑一轮]/[总结成卡]/[关掉]照旧。
- 旧线程：`participants=[原role]` 退化渲染。

## 测试（RIPR）

- Domain：旧行回落三件；join 校验；caps；`say_pair` 不动。
- Application：happy（3 人→3 turns+1 综合，publish≥4）；失败保留+重试补剩余；
  lenient；known 同路；abort+resume；重入 409；join 下一轮生效。
- API：4 端点 + ThreadView 新字段 + parity。
- Contracts：domain 无新外部 import；prompt 已注册。
- 前端：panel 配置/循环/分组综合/停止/插一句排队/拉人/旧线程/总结成卡不动。
- 真跑（隔离跑道 scratch 项目）：2 角色×2 轮 + 插一句 + 中途停止 + resume + 总结成卡进箱。
