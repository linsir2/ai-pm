## 0. 要回答的问题

> **在同一批查询上，混合检索（词面+向量）相对纯词面（FTS5）的配对增量 Δ 是多少？**

```
逐查询 i：h_fts(i) ∈ {0,1}、h_hyb(i) ∈ {0,1}
Δ  = Σ (h_hyb(i) − h_fts(i))            ← 配对差之和
显著 = 只看不一致的：b=混合赢、c=词面赢 → 精确二项检验（双侧，下尾×2）
零倒退 = 逐条 h_hyb(i) ≥ h_fts(i)
```

**必须配对**：同一批查询、同一个语料、同一个切法 → 唯一差别是融合 → 归因干净。

## 1. 三个坑（都写进代码注释了）

1. **词面基线必须按同样的「一份材料最多 2 槽」去重**（`dedup_by_material`）——
   混合路一份材料只占 1–2 槽，基线不这样去重 → 同一份材料的 5 个块占满 top5
   → **口径不对**。
2. **符号检验是下尾×2**（不是上尾）→ 否则 3 赢 0 输会算出 p=1.0。
3. **观测行只能有一个地方发** → 放检索器（只有那里知道分解），用例层不再重复记。
