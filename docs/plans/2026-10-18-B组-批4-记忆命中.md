# B 组批 4 · 记忆命中（现算 ＋ 遥测 ＋ 界面标）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development（推荐）或
> superpowers:executing-plans 逐任务执行。

**Goal:** 算出"最近 N 轮一次都没被引用过"的记忆条目，**在记忆抽屉里**标「久未使用」，
并给一份离线遥测表；**提示词一个字不动**。

**Architecture:** 命中是**现算**（`memory.py` docstring 早就写着"**不存计数器**：命中与否现算"）：
纯函数 `unused_entries(entries, cited_by_round, *, window)`；引用集来源是**已有**的
`assembly.cited_eids(proposals, questions)`（不新造）。标记只进 `WorkspaceView` 的只读投影。

**Tech Stack:** Python 3.13 · pytest · React 18 + TS strict · vitest

**Spec:** `docs/plans/2026-10-18-B组-设计.md` §5

## Global Constraints

- **提示词零改动**：`render_memory` / `render_memory_state` 一个字不改（M6f：ID 泄漏炸过整趟席位；
  且"久未使用"会让模型误弃仍有效的旧教训）。用一条**守卫测试**钉死。
- **不存计数器、不加列、不加表**（`memory.py` docstring）。
- **只标不删**：删除入口仍只有 `DELETE /projects/{id}/memory/{id}`。
- 窗口 `MEMORY_USAGE_WINDOW = 10`（与 `DIGEST_LIMIT=3`、`MEMORY_LINE_LIMIT=20` 同处风格）。

```python
from pmstudio.domain.memory.memory import unused_entries


def _entry(memory_id, refs=("E1",)):
    from datetime import datetime
    from pmstudio.domain.memory.memory import MemoryEntry, MemoryKind
    from pmstudio.domain.shared.ids import EvidenceId
    return MemoryEntry(
        memory_id=memory_id, kind=MemoryKind.LESSON, text="不要做多租户",
        refs=tuple(EvidenceId(r) for r in refs), round_id="r0",
        created_at=datetime(2026, 10, 1), updated_at=datetime(2026, 10, 1),
    )


class TestUnusedEntries:
    def test_never_cited_entry_is_unused(self):
        entries = (_entry("mem-1", refs=("E3",)),)
        cited = {"r-1": frozenset({"E1"}), "r-2": frozenset({"E2"})}

        assert unused_entries(entries, cited, window=10) == frozenset({"mem-1"})

    def test_cited_in_any_recent_round_is_used(self):
        entries = (_entry("mem-1", refs=("E3",)),)
        cited = {"r-1": frozenset({"E1"}), "r-2": frozenset({"E3"})}

        assert unused_entries(entries, cited, window=10) == frozenset()

    def test_window_keeps_only_the_last_n_rounds(self):
        """R：窗口**含端点**——最近 window 轮里引用过就算命中，更早的不算。"""
        entries = (_entry("mem-1", refs=("E3",)),)
        # 11 轮：最早那轮引过，最近 10 轮没引过 → 判"久未使用"
        cited = {"r-early": frozenset({"E3"}), **{f"r-{i}": frozenset() for i in range(10)}}
        ordered = ["r-early", *[f"r-{i}" for i in range(10)]]  # 由调用方按时间升序给

        assert unused_entries(entries, cited, window=10, order=ordered) == frozenset({"mem-1"})

    def test_no_entries_means_nothing_to_report(self):
        assert unused_entries((), {}, window=10) == frozenset()
```

> **接口说明（写进实现 docstring）**：`cited_by_round` 是**映射**，窗口要"最近 N 轮"必须有顺序
> ——所以再收一个 `order: Sequence[str]`（按时间**升序**的 `round_id`），只取尾部 `window` 个。
> 这不是多余参数：映射本身没有顺序，靠 `dict` 插入序是隐式契约，测试里说不清。

```python
def unused_entries(
    entries: Sequence[MemoryEntry],
    cited_by_round: Mapping[str, frozenset[str]],
    *,
    window: int,
    order: Sequence[str] = (),
) -> frozenset[str]:
    """最近 `window` 轮里**一次都没被引用过**的记忆条目 id。

    **现算，不落库**（`ProjectMemory` 的既有口径：命中与否现算，删掉候选不建计数字段）。
    `order` 是按时间**升序**的 `round_id`；只取尾部 `window` 轮（映射没有顺序，
    不许靠 `dict` 插入序——那是隐式的，测试里说不出口）。

    判据是**交集非空即命中**：记忆的 `refs` 只要出现在任何一轮的"交代过的编号"里，
    就算它被用上了（模型可能引用它的出处而不是它自己）。
    """

    if not entries:
        return frozenset()
    recent = order[-window:] if order else list(cited_by_round)[-window:]
    cited: frozenset[str] = frozenset().union(
        *(cited_by_round[round_id] for round_id in recent)
    )
    return frozenset(
        entry.memory_id
        for entry in entries
        if not {str(ref) for ref in entry.refs} & cited
    )
```
