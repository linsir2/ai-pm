# P3a 实现计划 v2：统一联网申请 / 授权 / 执行

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.
> 本计划只做 **P3a** 和 **P2 测试债**；P3b/P4 不做。

**Goal:** 把联网从“Analyzer 提名 → 复述卡按 query 字符串勾选 → opening 一次性执行”升级为“三方结构化申请 → 人逐条批准 / `allow_web` 自动批准 → **批准即执行** → 请求状态可追”，同时保留旧 `web_queries` 读兼容。

**Architecture:** 新增 domain `WebRequest`（5 状态）与 `Round.web_requests/allow_web`；旧 `web_queries` 只读派生、只写新键。把 `SubmitOpening` 的联网执行搬进 `application/web_research.py`；`DecideWebRequest` 走 `RoundRunner`，网络在 UoW 外，批准后立即执行并返回 `RoundView`。多步执行复用已有 E 号，web 结果按 `WEB_BUDGET` 选；不新增 `waiting_on`/SSE/DB/`DropSource`。

## 0. 已拍板的产品决定

1. **批准即执行**：用户点“批准/查”就在本次 HTTP 请求里联网，结果/E 号/请求状态一次返回；不新增 `waiting_on`。按钮 loading/超时可见。
2. **额度**：
   - 每方（analyzer/seat/integrator）最多 **3 条提案**；
   - 每轮最多 **3 条执行**（`approved/done/failed` 计数；`rejected/proposed` 不占）；
   - UI 显示剩余执行名额；执行名额满时不能再批准。
3. **旧数据按 step 迁移**：
   - `step == claims_ready`：旧 `web_queries` → proposed；旧 `web_queries_chosen` → approved（尚未执行）。
   - `step != claims_ready`：旧 `web_queries_chosen` → done（不重跑）；旧未勾选 → proposed。
   - 未提名的 chosen 补 legacy analyzer request，`why="旧版复述卡勾选，无逐条理由"`。
   - 只在 `web_requests` 键缺失时迁移；新轮只写 `web_requests/allow_web`，旧键只读派生。

## 1. 数据流

```text
Analyzer: ClaimsPacket.web_queries -> WebRequest(origin=analyzer, proposed)
  -> Round.attach_web_requests (per-origin cap 3, dedupe normalized query)

Opening:
  OpeningRequest {allow_web, approved_request_ids, web_queries(legacy)}
  -> validate; compute approved (ids + legacy queries; legacy 4 仍按旧工具上限 422)
  -> WebResearch.execute (network outside UoW, before any write)
  -> one UoW: submit_opening, materials/EIDs, requests done/failed, drops
  -> no approved request => no web call

Seat: SeatPacket.web_requests -> attach in _review_one UoW
Integrate: IntegrationPacket.web_requests -> attach in final integration UoW

Next model step (RunSeatRound/IntegrateRound):
  allow_web=True -> auto-approve proposed seat/integrator while execution slots remain
  approved requests -> WebResearch.execute before prepare
  integrator's own new requests not executed in the same integration

Decision:
  POST /rounds/{id}/web-requests/{rid}/decision {approve|reject}
  -> DecideWebRequest (RoundRunner) 
  -> approve: claim approved in UoW -> network outside -> one UoW materials/EIDs/done|failed + round.updated
  -> reject: UoW rejected, no network
  -> 404 unknown, 409 already decided/not pending/RoundBusy
```

**不做**：第 4 次 `waiting_on`、把 web 放进材料投影、把 `web_queries` 写回旧键、在 decision 里绕 UoW/事件、发号给未选中块。

**`WebResearch`**
- 搬 `_search/_search_one/_keep/_record_tool_call`；保留并发搜、按序落、一条结果一个 E 号、`WEB_BUDGET`、失败/没结果/预算丢条。
- **EID 复用**：执行前读 `Round.materials` 的 `(material_id, chunk_id)→eid`；已有块复用，不重复 `ledger.record`；新选中结果才发新号。多条执行累计不得产生孤儿号。
- **跨执行 web 预算**：把已有 web 材料 + 新结果一起 `select_chunks(..., budget=WEB_BUDGET, cost=web_block_cost, section_overhead=WEB_SECTION_OVERHEAD)`；只渲染选中集合；未选中不发新号；已发号但本步未选中的旧块可保留在 `Round.materials`（历史），但不再发新号。
- `execute(round_id, requests, pass_index)`：网络外；返回 picks/state/result_note/drops；调用方一个 UoW 写 materials/ledger/requests。
- `execute_approved(round_id, pass_index)`：取 approved（顺序固定）；`allow_web` 时在 UoW 里把 proposed seat/integrator 逐条 approved，直到 3 个执行名额满；然后执行；失败 `state=failed` + `result_note` + `TOOL` drop；不执行刚产生的 integrator 请求。
- 工具上限：`min(tool.max_queries, MAX_WEB_EXECUTIONS)`；无工具时禁止 allow_web/批准，报可读错误；`_checked_queries` 仍留在 `SubmitOpening` 处理旧字符串。

**执行点**
- `SubmitOpening`：**先网络、后 UoW**：读/校验 → 计算 approved（新 ids + legacy queries）→ `WebResearch.execute`（UoW 外）→ 一个 UoW：`submit_opening`、materials/EIDs、requests done/failed、drop。网络中途崩溃仍停在 opening。
- `RunSeatRound`/`IntegrateRound`：进入模型步前 `execute_approved`；`allow_web` 自动批准 seat/integrator。
- `DecideWebRequest`：立即执行（B4）。

**R**
- 未授权不执行；approved 执行一次；allow_web 自动批准；失败无半 E 号；一条结果一个 E 号；多步执行不重复 E 号；web 总预算 ≤2000；integrator 本轮请求不当场执行；旧 `web_queries` 行为不变（未提名 query 仍执行）。
- 真 SQLite + 替身 Tavily e2e；多步执行 e2e。

## 4. 风险/回滚

| 风险 | 缓解 | 回滚 |
|---|---|---|
| 批准后网络慢 | 按钮 loading/超时；失败 state=failed 不判死 | 关 allow_web/隐藏卡 |
| 多 worker 重复执行 | UoW 内 claim approved；EID 复用；decision 第二次 409 | 单 worker/停用 decision |
| 旧迁移重跑 | step 判定 done/approved；旧键只读 | revert B1 |
| E 号孤儿 | 复用 `(material_id,chunk_id)`；选中才发号；跨执行 web budget | revert B3 |
| 三方额度 starvation | 每方 3 提案、每轮 3 执行；名额满明确 | 调整常量 |
| 新端点绕轮锁 | RoundRunner/命令/路由守卫 | 不暴露 UI |
