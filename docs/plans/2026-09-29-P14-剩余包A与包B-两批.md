## 2. 口径（要作者看的几条）

| # | 口径 | 理由 |
|---|---|---|
| C1 | C4 的判据只认**行为**：某一轮"**给过** N>0 条 `proposed`（"它提议的"那一组）**且一条都没被接受**"记一次；遇到"没走到确认的轮"（`accepted is None`）就**停**，不跨过去数 | 我们要的是"这位用户确实从不采用提议"，不是"他这几轮恰好没提议"；没确认的轮什么也说明不了 |
| C2 | 连续 **3** 轮触发；提示走**草案卡 `advisories`**（前端已经在渲染），不改按钮默认值、不自动关闭任何东西 | `04` C4 原文就是"提示"；自动关掉一个专业面会悄悄让文档少一块 |
| C3 | 存的是**事实**（连续几轮 / 给了几条 / 收了几条），**文案在投影层**（DTO） | 与 `feature_coverage_advisory` 同一个范式；将来改文案不用动数据 |
| C4 | C4 的查询**只读、不建表**：`WorkspaceIndex.recent_rounds(project_id, limit=5)` 自带 `LIMIT`，只解析 payload 里那三个键 | `WorkspaceIndex` 的定位就是"只读查询投影，不是第二份真相源"（`ports.py:112`） |
| C5 | **C6 只放宽问卷闸门，不提高席位轮上限**：`dig` 需要 `can_begin_seat_round`，到顶就明确报错（`SeatRoundLimitReached`） | 席位轮上限（3）是防"无限烧模型"的兜底；真要再深挖，用户可以新开一轮输入 |
| C6 | `dig` 之后**要能问回来**：出草案时轮内队列**不再清空**（把 `clear_deferred()` 换成"只看不取"），重新整合时它们是 carried | 清空之后那些题只剩"落 s11"一条路，用户点"继续深挖"就会得到一份**和刚才一样**的草案——那还不如不给这个按钮 |
| C7 | `dig` 是**新开一次席位轮**（`_begin_seat_round`），不是"拿旧意见再整合" | 用户的诉求是"再想想、再问细一点"；拿旧意见重放只会重排同一份草案 |

    def confirm(
        self,
        version_no: int,
        *,
        proposed_offered: int = 0,
        proposed_accepted: int = 0,
    ) -> None:
        self._require_step(Step.AWAITING_CONFIRM)

        self._proposed_offered = proposed_offered
        self._proposed_accepted = proposed_accepted

    @property
    def proposed_offered(self) -> int | None:
        return self._proposed_offered

## 5. 数据流（P14 改完之后）

```
确认草案 ─► ProposalCommitter.commit
              ├─ 解析 accepted
              ├─ 数"它提议的"：给了 N 条、收了几条 → Round.confirm(version_no, proposed_offered=…, proposed_accepted=…)
              └─ 文档写一版（唯一写路径不变）

下一轮出草案 ─► IntegrateRound
              ├─ index.recent_rounds(project, limit=5)       ← 只读，最新在前
              ├─ proposal_ignore_streak(...)                 ← 纯函数
              ├─ round_.remember_proposal_ignore_streak(n)   ← 落轮次（事实）
              └─ 草案卡 advisories：连续 3 轮没采用 → 一句提醒

用户在草案卡点"继续深挖" ─► POST /rounds/{id}/dig ─► Round.dig()
              ├─ 清掉未确认的草案（文档没被写过，不用回滚）
              ├─ extra_batches += 1（问卷闸门 +1 批）
              ├─ 新开一次席位轮（到顶就明确报错）
              ├─ step: awaiting_confirm → seats_running   ← 新的合法转移
              └─ 轮内队列**保留**（出草案不再清空）→ 重新整合时它们是 carried 题
                    └─► 席位轮 → 整合（这次问得出来）→ 问卷 / 再一次草案
```
