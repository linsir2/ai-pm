## 0. 用户原话与定位

| 用户报的 | 根因 |
|---|---|
| "复述卡被吞了，跑第二轮没看到" | `useRoundDrafts`：①collapsed **不随换轮重置**——上一轮收起过，新轮就永远收；②自动展开的 `useEffect` **不认 opening**，`mode` 一变成 opening 也不弹。新 UI 的 `drawerFor` 只受 `collapsed` 压制 → 卡被吞 |
| "证据引用这么多一样的" | 一张功能卡上**三层出处**：字段头的并集胶囊（FeatureBlock:94 `flatMap`）+ 逐条 `EntryList` 胶囊 + 卡底的 `EvidenceChain`。字段头那层和逐条完全重复 |
| "点击跳转，他就在原地/文档内容本身就是证据吗" | `jumpToEvidenceById` 优先走 `used_by[0]` → 滚到**引用它的那条文档条目**（就是正在看的）→ 原地不动。真身（那轮复述卡里的主张原话，`data-eid`）反而够不着 |
| "证据占位也太大" | 胶囊 `line-height:1.7`/`gap:4px`，挤在条目右列还换行成 2×2 |

## 1. 已改（全部最小 diff）

1. `useRoundDrafts`：换轮重置补 `setCollapsed(false)`；自动展开 `useEffect` 把
   `opening` 与问卷/草案同权。回归测试两条进 `useRoundDrafts.test.tsx`。
2. `App.jumpToEvidenceById` 重排：**先跳编号的真身（轮次里的主张/材料块）**，
   跨轮 → `viewRound(那一轮)` 后再滚；本轮但卡收起 → 先展开浮层再滚；
   只有连轮次都归属不上的编号才退回"滚到引用它的条目"。
   （解释口径："文档条目不是证据，它是被证据支撑的结果；编号指回你当时怎么说的话"）
3. `FeatureBlock` 字段头的并集胶囊删除（`EvidenceChip` import 一并删）——
   逐条 + 卡底链条保留，不变式（先有编号再有内容）不动。
4. 胶囊密度：`line-height 1.7→1.5`、`padding 0 4px→0 3px`、`gap 4px→3px`
   （尺寸令牌不动，`tokens.test` 守住）。
