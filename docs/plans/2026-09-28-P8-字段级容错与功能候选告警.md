## 1. 执行范围

**做**

## 2. 口径（要作者拍板的四处）

**D1 · 字段级归一化三档（推荐）**

| 档 | 规则 | 例 | 为什么安全 |
|---|---|---|---|
| L1 | **列表字段**收到 `null` → `[]` | `evidence_refs: null` → `[]` | 空列表在本仓库是**有明确定义**的：席位意见没依据 → 走既有降级（`basis_note` 标注"模型没给依据"）；提案没依据 → schema `min_length=1` 照旧失败（GB1 不破） |
| L2 | `list[str]` 字段收到**字符串** → 单元素列表 | `evidence_refs: "E4"` → `["E4"]` | 一个编号写成一个字符串，意图唯一；`"E4, E9"` 不拆，交给"编号不存在"那条报错 |
| L3 | **非 Optional、有默认值**的字段收到 `null` → 删掉这个键（用默认值） | `kind: null` → 默认 `gap` | 模型写 `null` = "没给值"，而 schema 给了默认值；这类字段是**分类提示**，不是内容 |
| — | 例外：`op`、`entry_id`、`form` **不适用 L3** | `op: null` → 照旧 schema 错 | `op`/`entry_id` 决定"写/改/删哪一条"；`form`（question/judgment）决定**这条意见进不进账本、有没有编号**——都不许用默认值悄悄改语义 |

**D2 · 归一化只在"形状可机械判定"时发生**

规则由 **schema 注解**推导（`list[str]` / `list[BaseModel]` / 嵌套 `BaseModel`），不写字段名字表；
于是以后加字段自动被覆盖，也不会出现"某张表忘了加"的漂移。

**D3 · 告警的判据（宁可漏报，不许误报）**

```
claims 里出现了带 feature_slug 的主张（= 用户这轮点到了功能）
  且 draft.proposals 里没有任何 section_id=s5 且带 feature_slug 的提案
→ 告警（放在 advisories[0]，草案卡置顶）
```

- **不**把"s5 字段没填满"算进来（那是就绪度的事，已经有了）；
- **不**在"本轮输入本来就没提功能"（如 `edge-only-preference`）时报警；
- **不**在"功能内容由后续轮次补"时反复骚扰——告警只挂在**当前这一轮**的草案卡上（DTO 投影，不进文档）。

**D4 · 告警文案（人话，且给出下一步）**

```
⚠ 这一轮一条功能内容都没有：你点到了「order-export、repair-order、stats-report」3 个功能，
但草案里 s5 没有任何提案。要么这一轮补上功能内容（再提一轮，把每个功能一句话说清），
要么在本轮明确"这轮不写功能"。
```

```python
# schemas.py：import 区
from types import UnionType
from typing import Literal, Union, get_args, get_origin

#: 这几个字段**不适用**"null → 用默认值"：
#: `op` / `entry_id` 决定写/改/删哪一条；`form` 决定这条意见进不进账本（有没有编号）
_WRITE_SEMANTICS_FIELDS = frozenset({"op", "entry_id", "form"})


def _is_model(annotation: object) -> bool:
    return isinstance(annotation, type) and issubclass(annotation, BaseModel)


def _allows_none(annotation: object) -> bool:
    if annotation is type(None):  # noqa: E721
        return True
    args = get_args(annotation)
    return type(None) in args


def _normalize_value(value: object, *, annotation: object) -> object:
    """按注解归一化一个值：列表字段收 null/字符串；嵌套报文递归。"""

    origin = get_origin(annotation)
    if origin in (Union, UnionType):
        inner = [item for item in get_args(annotation) if item is not type(None)]
        if value is None or len(inner) != 1:
            return value
        return _normalize_value(value, annotation=inner[0])
    if origin is list:
        args = get_args(annotation)
        item_type = args[0] if args else object
        if value is None:
            return []
        if isinstance(value, str) and item_type is str:
            return [value]
        if isinstance(value, list) and _is_model(item_type):
            return [
                _normalize_model(item, model=item_type) if isinstance(item, dict) else item
                for item in value
            ]
        return value
    if _is_model(annotation) and isinstance(value, dict):
        return _normalize_model(value, model=annotation)
    return value


def _normalize_model(payload: object, *, model: type[BaseModel]) -> object:
    """按字段表过一遍：形状归一化 + （非 Optional、有默认值）的 null 删键。"""

    if not isinstance(payload, dict):
        return payload
    fixed: dict[str, object] = {}
    for name, value in payload.items():
        spec = model.model_fields.get(name)
        if spec is None:
            fixed[name] = value  # 多余的键交给 pydantic（默认忽略）
            continue
        if (
            value is None
            and name not in _WRITE_SEMANTICS_FIELDS
            and not spec.is_required()
            and spec.default is not None
            and not _allows_none(spec.annotation)
        ):
            continue  # 用 schema 默认值
        fixed[name] = _normalize_value(value, annotation=spec.annotation)
    return fixed


def _normalize_fields(payload: object, *, model: type[BaseModel]) -> object:
    """字段级归一化：机械可判的就地修，内容与写入语义一律不动。

    真跑实测（P7 验证留样 7）：席位把 `evidence_refs` 写成 `null` → 整席位判死。
    "某个字段没给"和"某个字段给了但形状不对"是两件事：前者能用 schema 的默认值/空列表表达，
    后者还能用"单值写成数组"的写法表达——这两类都归一化，**内容字段与 op/entry_id 一律不救**。
    """

    return _normalize_model(payload, model=model)


def parse_packet[T: BaseModel](text: str, model: type[T], *, purpose: str) -> T:
    ...
    payload = _normalize_payload(payload, model=model, purpose=purpose)
    payload = _normalize_fields(payload, model=model)      # ← 新增
    ...


def parse_packet_trimmed[T: BaseModel](text, model, *, purpose):
    ...
    payload = _normalize_payload(payload, model=model, purpose=purpose)
    payload = _normalize_fields(payload, model=model)      # ← 新增
    ...
```

def feature_coverage_advisory(round_) -> str | None:  # type: ignore[no-untyped-def]
    """这一轮"点到了功能、却一条功能内容都没有"的置顶告警（报告 F1）。

    判据刻意保守：只有在"主张点名过功能"且"草案一条 s5 功能提案都没有"时才报。
    """

    if round_.draft is None:
        return None
    named = sorted(
        {
            str(claim.target.feature_slug)
            for claim in round_.claims
            if claim.target.feature_slug is not None
        }
    )
    if not named:
        return None
    has_feature_content = any(
        proposal.target.feature_slug is not None for proposal in round_.draft.proposals
    )
    if has_feature_content:
        return None
    return (
        f"⚠ 这一轮一条功能内容都没有：你点到了「{'、'.join(named)}」"
        f"{len(named)} 个功能，但草案里 s5 没有任何提案。"
        "要么这一轮补上功能内容（再提一轮，把每个功能一句话说清），"
        "要么明确「这轮不写功能」。"
    )


# round_view 里：
    if round_.draft is not None:
        violations = ScopeGuard().check(...)
        warnings = {...}
        coverage = feature_coverage_advisory(round_)
        advisories = ((coverage,) if coverage else ()) + tuple(

**④ 我自己的疑点（拍板时看一眼）**

1. **L3 会不会太宽？** 我只让它作用在"非 Optional + 有默认值 + 不在黑名单"的字段上，
   实际命中的是 `kind`（题的分类）/ `type`（题的形态）/ `zone` / `origin_type` 这类**分类提示**字段。
   凡"会影响写入语义或编号分配"的（`op`/`entry_id`/**`form`**）都已经进黑名单，宁可失败。
2. **要 不要给内容字段一个"空字符串也算错"的更狠指引？** 现在内容字段的 `null` 只报"要是字符串"，
   模型可能改用 `""`——那会被领域校验拦（"必须写清问什么"）。我认为够了，不加。
3. **告警要不要也落一条 `Round.dropped` 留痕？** 我倾向不落：它是"这一轮的投影提示"，
   不是"某条意见没进卡片"；落进去会让留痕通道的语义变浑（P6 §11.0.7 同一口径）。
