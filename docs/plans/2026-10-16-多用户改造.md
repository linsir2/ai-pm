# 多用户改造 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把单用户本地应用改造成公网多用户应用： Vault 隔离（owner 列）+ 本地账号体系（注册审批/登录/session）+ Caddy 公网入口，每期独立可验收可回滚。

**Architecture:** 共享表 + `owner_id` 行级隔离（读过滤落仓储最底层，缺上下文直接抛）；认证只用 `argon2-cffi` + `secrets` + `hashlib`（无 ORM、无 JWT、无新服务）；`domain/` 零改动，身份只以 `UserId` 值对象进参；SQLite 单文件 WAL 不变，单 worker。

**Tech Stack:** Python ≥3.13 + FastAPI（现版本不动）+ sqlite3 标准库 + argon2-cffi（唯一新增依赖）+ React 18 + Caddy（网关）。

**Spec:** 本 plan 即 spec（改造书 v2 全文已由用户拍板，见本文件 §0；另需对照 `.codex/docs/设计/01-规格.md` 的非目标条款——实施后该条款改写由用户另行确认，不在本 plan 内）。

## Global Constraints

- 后端测试一律：`cd backend && PYTHONDONTWRITEBYTECODE=1 python3 -m pytest -q -p no:cacheprovider`；lint：`cd backend && python3 -m ruff check --no-cache .`。
- 前端测试一律：`cd frontend && npx vitest run`；类型：`cd frontend && npx tsc --noEmit`。
- `domain/` 不 import 任何外部包（`tests/architecture/test_domain_imports.py` 守着，argon2 也不许进）。
- 写入路径唯一：只有确认端点能写文档（`tests/architecture/test_write_path.py` 守着）。
- 越权一律 404（`unknown_*` 同档），不泄露他人 id 存在；admin 专属路由才用 403。
- token 只走 HttpOnly cookie，不进 localStorage。
- 不留痕跑法：`__pycache__` / `.pytest_cache` / `.ruff_cache` 不许进库（`.gitignore` 已有，用上面两条命令即不生成）。
- SECRET_KEY / FIRST_ADMIN 密码只走环境变量，模板进库真值不进库。

## §0 已拍板决策（执行者不得改，改即停下报批）

1. 部署：公网可访问（域名+HTTPS）。
2. 隔离：A 共享表 + `owner_id`（14 张内容表逐张加列加索引；`model_calls` 不加列，管理后台 join 查）。
3. 认证：`argon2-cffi` 直连（不用 pwdlib 包裝、无历史哈希要兼容）+ `secrets` + `hashlib`；不用 fastapi-users（maintenance-mode、无审批、强推 SQLAlchemy）、不用 authlib/fastapi-sso（不管本地密码）、不用 itsdangerous（无邮件/重置流，CSRF token 存 sessions 表比对）、不用 JWT/Redis/Postgres/OIDC/双 token。
4. 注册：开放注册 + 管理员审批（`status: pending→active`，不复用邮箱语义字段）。
5. 用户中心：个人（改密/改名/用量）+ 管理员后台（审批队列/用户列表/封禁/用量）。
6. 存量 5 项目全归首个管理员。
7. 首版只隔离不分享；owner 列写入后不可改（改归属=删了重建）。
8. 网关：Caddy 原生（TLS+反代），限流插件已砍（xcaddy 构建是运维债），限流全在应用层；Tunnel 可选叠加。
9. 并发：单 worker（uvicorn 默认即单，`dev.py` 写禁令注释）；`connect()` 显式 `timeout=10.0`（现在是 Python 默认 5.0 隐式值）；不加锁（49 个用例全 `async`、单事件循环线程内执行，事务都是短同步块；"模型调用一律在事务外"守卫已保證原子性，加锁是多余复杂）。
10. 登录防爆：内存滑动计数（ip+用户名维度，失败延迟+连败锁定，重启清零可接受）；失败统一文案+恒定耗时。
11. 会话：30 天滑动 / 90 天绝对上限；`last_seen_at` 半窗写一次；登出/封禁即删行吊销。
12. 用户名用任意名（不强制 email，省邮箱验证全套）；admin 管用户与用量、**不浏览他人文档内容**（Ruling 16）；要支持客服看用户文档需另立项。

"""密码学唯一落点：全仓只有这里碰密码哈希（`grep -rn argon2 src/` 必须只有本文件）。"""

from argon2 import PasswordHasher
from argon2.exceptions import VerifyMismatchError

_hasher = PasswordHasher()  # 默认即 RFC 9106 LOW_MEMORY，已超 OWASP 下限，不自创参数


def hash_password(password: str) -> str:
    return _hasher.hash(password)


def verify_password(hash: str, password: str) -> bool:
    try:
        return _hasher.verify(hash, password)
    except VerifyMismatchError:
        return False
```

CREATE TABLE IF NOT EXISTS users (
  user_id     TEXT PRIMARY KEY,
  username    TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  status      TEXT NOT NULL DEFAULT 'pending',
  role        TEXT NOT NULL DEFAULT 'user',
  approved_by TEXT,
  approved_at TEXT,
  created_at  TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS sessions (
  session_id  TEXT PRIMARY KEY,
  user_id     TEXT NOT NULL REFERENCES users(user_id) ON DELETE CASCADE,
  token_hash  TEXT NOT NULL,
  expires_at  TEXT NOT NULL,
  last_seen_at TEXT NOT NULL,
  ip          TEXT NOT NULL DEFAULT '',
  user_agent  TEXT NOT NULL DEFAULT '',
  revoked_at  TEXT
);
CREATE INDEX IF NOT EXISTS idx_sessions_user ON sessions(user_id, expires_at);
```
