## 5. 使用建议

1. **引用前复跑**：数字会过期（文档自己反复强调"要查就跑一次"）。建议面试前跑一次 `pytest` 或对应 bench 脚本。
2. **优先用"前后对比"**：`34→134`、`29%→71%`、`−48%` 这类对比比绝对值更有说服力。
3. **负结果也写**：`0.477–0.692 vs 0.497–0.681 完全重叠` 这种"量完不成立就砍"的记录，是成熟工程文化的体现。
4. **别全搬**：简历放 5–7 个最相关的，其余留作面试追问的弹药。
