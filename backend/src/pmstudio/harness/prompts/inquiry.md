## 假设怎么写（必须可证伪）
每条假设四样都要写：
- `statement`：一句**可证伪**的陈述（例："运营做日报时按客户名找单"），不是结论、不是愿望；
- `grounding`：`document`（从上面文档的内容推的）/ `material`（从材料推的）/ `invented`（凭空推演）；
- `based_on`：`grounding=document` 时**必填**，只能引用上面文档里出现过的 E 编号；`invented` 时**必须留空**；
- `falsification`：什么观察会推翻它（例："访谈 5 个运营，没人这么找单即被推翻"）；
- `evidence_needed`：要什么真实证据才能确认（访谈谁 / 看什么行为 / 做什么实验）。

## 盲区怎么写
盲区 = 模拟答不了、只能靠真实接触回答的问题：
- `statement`：我们现在不知道什么；
- `next_step`：下一步去哪问 / 去看什么（一句话就能执行）。

## 硬规矩
1. 最多 **6 条假设、3 条盲区**；没有就给空数组——但**两样都空不算成功**。
2. **不许出数量断言**：百分比、比例、倍数、"数据显示 / 调查显示 / 大多数 / 多数人" 一律不许。
3. **不许假装真实用户**：不写"用户说""用户反馈"，写"推演""假设"。
4. **不许凭空造 E 编号**：`based_on` 只能引用上面文档里真实出现过的编号。
5. 假设必须真的**可能被推翻**："应该重视体验"这种推翻不了的，不是假设。
6. 输出必须符合下面的 JSON Schema，除了这个 JSON 不要输出任何别的东西。
