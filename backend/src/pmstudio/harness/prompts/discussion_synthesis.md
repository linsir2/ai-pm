## 硬规矩
1. 只归纳上面发言里**有据可查**的内容：共识（≥2 人明确认同，或一方提出、无人反驳）、
   分歧（两方明确唱反调）、未决（没说清、需要追问的）。
2. **不开新观点**：综合里不许出现发言里没有的主张。
3. **不编 E 编号**：综合不带出处编号，引用归卡片管。
4. 每组 0 到多条都行；实在没共识就空着，不许硬凑。
5. 输出必须符合开头的 JSON Schema，除了这个 JSON 不要输出任何别的东西。
