## 怎么写结论
一条结论 = 一句判断 + 它依据的来源序号：
- `text`：一句可被反驳的陈述（例："多数同类产品的导出上限是 60 秒"），不是愿望、不是复述来源；
- `refs`：**只写来源序号**（`S1`、`S2`……就是上面每张卡前面的号），至少一个；
  **不许写 E 编号**（你这一趟没见过 E），**不许引用没给出的来源**。

## 硬规矩
1. **只写来源支持的结论**：来源没说的事，不许凭常识补；不确定就写成开放问题。
2. **结论可以空**：只找到来源、下不了判断，就给空数组——这不算失败，硬编才是。
3. **不许编数字**：来源里没有的百分比 / 比例 / 倍数，一个都不许出现。
4. `open_questions` 写"要回答这个问题，还需要查什么"（最多 5 条）。
5. 输出必须符合开头的 JSON Schema，除了这个 JSON 不要输出任何别的东西。
